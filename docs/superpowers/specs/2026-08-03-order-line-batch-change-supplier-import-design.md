# 订单行列表 — 工具栏批量更换供应商设计

**日期**：2026-08-03  
**状态**：实现中  
**模块**：非连续出版物订单 / 订单行列表  
**关联**：
- 行内部分数量更换供应商：`2026-08-03-order-line-partial-change-supplier-design.md`（共用可迁出公式与撤订回写；批量不填套数，按行全量可迁出）

---

## 1. 背景与目标

用户在订单行列表勾选多行后，通过工具栏「更换供应商」打开与单行类似的弹窗（无套数字段），按各行可迁出套数生成一条待发订新订单。

### 1.1 目标

- 工具栏入口：勾选行状态均为已发订或处理中，且订户/资源类型/语种/采选方式一致
- 弹窗字段对齐单行（订单名称、供应商、预算、原因、备注），**不填套数**、**不做 Excel 导入**
- 每行迁出套数 = 该行可迁出套数；生成 1 新单 + N 新行
- 成功提示返回：新订单号、订单行种数、套数、册数

### 1.2 非目标

- Excel/模板导入
- 改造行内「更换供应商」套数逻辑
- 真实后端；前端 mock

---

## 2. 入口

| 项 | 约定 |
|----|------|
| 位置 | 订单行列表工具栏 |
| 文案 | **更换供应商** |
| 启用 | 勾选 ≥1 行；行状态均为**已发订**或**处理中**；且订户、资源类型、语种、采选方式相同（订户/采选方式取自关联订单） |
| 行内 | 单行弹窗含套数；与工具栏并存 |

---

## 3. 弹窗

参考单行更换供应商弹窗（FormModal）：

| 字段 | 必填 | 说明 |
|------|------|------|
| 订单名称 | 是 | 默认 `{首行关联订单名}-{yyyyMMddHHmmss}`（见时间戳后缀规格），可改；提交不校验重名 |
| 供应商 | 是 | 默认取首行关联订单供应商；按采选方式过滤 |
| 预算名称 | 条件必填 | 默认取首行关联订单预算；交换/捐赠可空 |
| 原因 | 是 | 撤订原因参数中使用中的原因 |
| 备注 | 否 | 写入新订单备注 |

不提供套数字段；各行按可迁出套数全量迁出。

---

## 4. 提交数据流

1. 校验表单与勾选范围一致性  
2. 校验每行可更换供应商且可迁出 ≥ 1  
3. 新建 1 条待发订订单头（继承首行关联订单 + 弹窗覆盖）  
4. 按勾选顺序为每行建新订单行；原行撤订段 += 可迁出套数，原因 = 弹窗原因  
5. 成功确认：「已生成新订单 {orderId}，订单行种数 {种}，套数 {套}，册数 {册}，是否立即查看？」→ 确定跳转订单列表
