## 1. 背景与目标

### 1.1 背景

馆员「所属馆」来自业务中台账号同步。权限校验若每次调用户信息接口，或每次按组织树倒推机构，成本高且易与四级馆藏地数据不一致。

馆员列表中的账号以**已关联订户**为主；未关联订户的账号默认不出现在业务馆员列表。

### 1.2 目标

1. 馆员列表在「订户名称」前增加只读列：**所属馆**、**所属机构**。
2. 同步馆员信息时写入所属馆，并按**四级馆藏地**倒推一次所属机构后落库。
3. 后续数据权限校验只读馆员主数据与关联订户，**不再**调用户信息接口、**不再**现场按四级树倒推。

### 1.3 非目标

- 不在 OMS 提供所属馆 / 所属机构编辑入口。
- 不改订户关联馆员的业务流程与候选池规则。
- 不改造中台同步协议细节（仅约定：中台提供所属馆；机构由 OMS 按四级树写入）。
- 本期不以「无订户账号是否出现在列表」为改造重点（默认业务列表以已关联为主）。

---

## 2. 方案

**采用**：同步落库双字段 + 列表只读展示（方案 1）。

| 方案 | 说明 | 结论 |
|------|------|------|
| 1 | 同步写 `branchId` + `institutionId`；列表展示两列；权限读缓存 | **采用** |
| 2 | 只落所属馆，机构每次倒推 | 否决（违背少倒推目标） |
| 3 | 双字段落库但列表不展示机构 | 否决（排障不便） |

**页面**：馆员列表 `/librarians`

**列序**（相关段）：

| 列 | 说明 |
|----|------|
| …馆员账号、馆员姓名 | 既有 |

| …关联日期、操作 | 既有 |

## 4. 数据模型

馆员主数据扩展（同步写入，OMS 不可编）：

| 字段 | 说明 |
|------|------|
| `branchId`（或与主数据一致的分馆标识 / 编码） | 所属馆；来自中台同步 |
| `institutionId` | 所属机构；同步时按四级馆藏地倒推后落库的冗余缓存 |

列表展示名由 id/编码解析；不以展示串作为权限依据。

## 5. 同步写入

### 5.1 触发

同步馆员信息（中台 → OMS 馆员主数据）时写入。不在每次权限校验时调用户信息或倒推。

### 5.2 中台输入

- 提供**所属馆**（分馆标识，须能与四级馆藏地树中的分馆节点对齐，如分馆编码）。
- **不要求**中台直接带所属机构。

### 5.3 倒推规则（同步时一次）

1. 用所属馆在**四级馆藏地**树中定位分馆节点（馆址 → 分馆 → 馆藏地）。
2. 取该节点上的 `institutionId`，写入馆员 `institutionId`。
3. **不以**本地 `org-hierarchy` 馆区映射为权威来源（避免与四级树不一致）。

### 5.4 失败与刷新

| 情况 | 处理 |
|------|------|
| 无所属馆 | `branchId`、`institutionId` 皆空 |
| 有所属馆但四级树找不到对应分馆 | 只落所属馆；`institutionId` 空 |
| 组织树 / 四级数据变更 | 不即时回写历史行；下次同步覆盖 |

---

## 6. 权限读取

### 6.1 原则

校验只读馆员主数据已落库字段 + 关联订户：

- 不调用户信息接口
- 不按四级树现场倒推机构

### 6.2 机构范围解析顺序

1. **有关联订户** → 订户所属机构合集（去重保序）
2. **无关联订户** → 读馆员落库的 `institutionId`（有则 `[institutionId]`，否则 `[]`）
3. **皆无** → 空范围

### 6.3 所属馆在权限中的角色

- 列表展示与排障。
- **有关联订户时不参与**机构范围计算。
- 无订户时也不再现场倒推：直接用已落库的 `institutionId`。

### 6.4 与既有隔离规格的关系

- 对齐「订户机构合集优先；无订户则用所属馆侧机构」的大方向。
- **差异**：无订户时的机构取自**同步落库的 `institutionId`**，不再运行时 `branch → 四级树/馆区` 倒推。
- 设置类模块的 `resolveInstitutionScopeIds()`（及同类入口）按本节更新；采访业务有订户时仍以订户合集为准。

## 7. 原型 / Mock 约定

- 馆员 mock 行可带 `branchId`；初始化或「同步」演示时按四级树写入 `institutionId`。
- 列表列定义增加所属馆、所属机构；展示解析失败时为「—」。

---

## 8. 验收要点

1. 馆员列表在订户名称前可见只读「所属馆」「所属机构」。
2. 模拟同步：仅有分馆标识时，能按四级树写入正确 `institutionId`；找不到分馆时机构为空。
3. 有关联订户：机构范围 = 订户机构合集，不读（或不依赖）落库机构覆盖合集。
4. 无关联订户且有落库 `institutionId`：机构范围为该机构；过程中不调用户信息、不访问四级树倒推。
5. OMS 无编辑所属馆 / 所属机构入口。
