# 条码校验规则 · 所属机构改为所属馆

**日期**：2026-10-22  
**状态**：已确认  
**模块**：设置 · 条码校验规则（`/barcode-rule`）  
**关联**：
- 原设计 `2026-09-15-barcode-validation-rule-config-design.md`（所属机构口径）
- 四级馆藏地 `location-level4.js`（所属馆选项权威来源）
- 订户「所属组织 → 所属馆」产品口径（同源四级三级分馆；本需求不改订户表单实现）
- library 隔离备选 `2026-10-21-library-data-isolation-design.md`（条码规则属 library 轨；本需求不落地 S0～S3 墙）

---

## 1. 背景与目标

条码校验规则现按**所属机构**（`institutionId`）维护；列表、筛选、表单与唯一性均以机构为维度。产品要求改为**所属馆**：与订户所属馆同源，取自四级馆藏地接口树的**三级（分馆）节点**，不是馆址管理本地分馆主数据。

### 1.1 目标

1. 规则归属从机构改为所属馆；落库 `libraryId` + `libraryCode`，展示 `libraryName`。
2. 选项直接从四级树抽取 `type === 'branch'` 的三级节点；表单为单一可搜索下拉（无机构→馆区级联）。
3. 唯一性下沉到「同一所属馆」：`ruleCode`、`barcodeType` 均不可重复。
4. 同步 PRD（§5.10）、页内 PRD 抽屉数据与原条码规则设计中的机构口径表述。

### 1.2 非目标

- 不改造「条码号供应商代码」的所属机构。
- 不接入验收自动分配 / 扫描头尾剥离。
- 不落地 library 数据隔离墙（S0～S3 过滤）；仅改归属字段与 UI 口径。
- 不改订户表单现有实现（与本需求解耦）。

---

## 2. 方案选型

| 方案 | 说明 | 结论 |
|------|------|------|
| 1. 归属字段换成馆，选项抽四级三级节点 | `libraryId`/`libraryCode`；唯一性按馆；去掉规则上机构字段 | **采用** |
| 2. 双写 library + 派生 institution | UI 只露馆，仍存机构 | 否决（按馆唯一后机构冗余易漂移） |
| 3. 仅改文案「所属馆」，底层仍机构 | 表面改名 | 否决（与「真正所属馆」冲突） |

---

## 3. 数据模型

| 字段 | 必填 | 说明 |
|------|------|------|
| `libraryId` | 是 | 四级树三级分馆节点 `id` |
| `libraryCode` | 是（写入时冗余） | 节点 `code`；筛选/展示稳定匹配 |
| `libraryName` | 派生 | 展示用，建议 `code \| name` |
| `institutionId` / `institutionName` | — | **规则行删除**；不再双写 |

**选项**：复用/对齐 `collectLevel4BranchOptions(LEVEL4_LOCATION_TREE)`（或等价抽取）；展示可搜索单选。

**唯一性**：

- 同一 `libraryId` 下 `ruleCode` 不重复
- 同一 `libraryId` 下 `barcodeType` 不重复
- 不同馆允许相同规则代码 / 条码号类型

**校验文案**：

- `请填写所属馆`
- `该所属馆下规则代码已存在`
- `该所属馆下条码号类型已存在`

## 4. 信息架构与页面

### 4.1 列表

- 列「所属机构」→「所属馆」（`libraryName`）
- 其余列与行操作不变
- 同馆可多条「使用中」并存（启停粒度仍为单条规则）

### 4.2 筛选

| 字段 | 控件 | 说明 |
|------|------|------|
| 所属馆（`libraryId` 语义；筛选项按展示名） | 下拉 | 全部 + 四级三级分馆；精确匹配展示名 |
| 条码号类型 / 规则代码 / 状态 | 同现网 | 不变 |

### 4.3 新增 / 编辑弹窗

| 字段 | 必填 | 控件 | 说明 |
|------|------|------|------|
| 所属馆（`libraryId`） | 是 | 可搜索单选 | 四级三级分馆；**不**级联机构/馆区 |
| 规则代码 / 条码号类型 / 总长度 / 组成方式 / 状态 / 样例 / 备注 | 同现网 | — | 唯一性改为同馆 |

- 编辑时所属馆**可改**；保存时按新馆做唯一性校验。

### 4.4 启停 / 删除弹窗

- 只读展示：所属馆、规则代码、条码号类型
- 仅已停用可删（不变）

## 5. Mock 迁移

| 原数据 | 新挂载 |
|--------|--------|

- 筛选项 / 下拉统一从四级树抽三级分馆。

## 7. 验收标准

1. 列表 / 筛选 / 新增编辑 / 启停删文案均为「所属馆」；选项来自四级三级分馆。
2. 同馆下规则代码或条码号类型重复被拒；不同馆可同码同类型。
3. 首图演示规则挂 `ST001`；园区馆规则挂 `YQLIB` 且可筛选到。
4. 规则行无 `institutionId`；PRD 与页内 PRD 抽屉与实现一致。
