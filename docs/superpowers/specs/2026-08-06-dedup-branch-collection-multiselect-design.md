# 查重范围：所属分馆 / 馆藏地多选

## 背景

查重配置弹窗（`DedupConfigModal`）中「所属分馆」「所属馆藏地」现为可搜索单选。业务需要支持多选；选中标签较多时触发器需限制高度并出现纵向滚动条。

## 行为

### 多选与空选

- 所属分馆、所属馆藏地均为可搜索多选；展示仍为「编码 | 名称」。
- 未选任何分馆 / 馆藏地：仍视为**不限范围**，允许提交。
- 提交字段改为数组：`branchCodes: string[]`、`collectionCodes: string[]`（「订单查重」或隐藏范围时提交空数组）。

### 级联（并集）

- **未选分馆**：馆藏地展示全部使用中馆藏地，可选。
- **已选一个或多个分馆**：馆藏地选项 = 这些分馆下使用中馆藏地的**并集**。
- 变更分馆后：剔除不再属于当前馆藏地选项集的已选编码。

### 下拉交互

- 支持关键字过滤选项；点选后不关闭下拉（便于连续多选）。
- 顶部提供**全选 / 反选**：作用域为当前 `filteredOptions`（有搜索关键字时仅可见项；无关键字时即全部 options）。全选勾选态 = 当前过滤结果均已选中；反选对调过滤结果内的已选/未选，不改变过滤外已选。
- 已选值以标签展示在触发器内，可逐个 × 删除。

### 触发器滚动

- 已选标签区域设置 `max-height`（约三行，`max-h-24` / 96px），`overflow-y: auto`。
- 超出后出现纵向滚动条；下拉列表高度逻辑不变。

## 实现要点

| 项 | 说明 |
|----|------|
| 组件 | 新增 `SearchableMultiSelect.vue`（基于现有单选的 value/label、Teleport、搜索；`modelValue` 为 `string[]`） |
| 查重弹窗 | 改用多选组件；`selectedBranchCodes` / `selectedCollectionCodes` |
| 馆藏地 options | 扩展 `buildCollectionCodeSelectOptions` 支持 `branchCode` 为字符串或字符串数组（数组 → 并集过滤） |
| store / `performOrderLineDedup` | 接收并保存 `branchCodes` / `collectionCodes`（mock 过滤可暂保持「已存即生效」的后续能力，与现单选一致） |
| PRD | 同步 5.3.5.5：单选 → 多选、并集级联、标签区滚动、字段名数组 |

## 非目标

- **不**给 `SiteMultiSelect` 增加全选/反选（该组件保持原样；全选/反选仅属于 `SearchableMultiSelect`）。
- 不在本变更中实现馆藏结果按多选范围的真实过滤算法（若 mock 尚未按单选过滤，多选同样只落库配置）。

## 验收

1. 可多选多个分馆；馆藏地列出所选分馆下馆藏地并集。
2. 未选分馆时馆藏地展示全部选项且可选；变更分馆后无效馆藏地被清除。
3. 选中标签超过约三行高度时，触发器内出现纵向滚动条。
4. 空选可提交；提交配置含 `branchCodes` / `collectionCodes` 数组。
5. 下拉支持搜索与全选/反选；点选选项后下拉保持打开。
