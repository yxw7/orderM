同步点清单 P1–P10

与 drawio 边缘标签一致；同一 Pn 可在预验收与上机加工复用。

#同步点方向阶段说明
P1查询订单行图灵 → 订单预验收；上机多卷返回订单行信息
P2同步单册订单 → 元数据两阶段多处创建/更新元数据单册
P3根据记录号查单册列表及单册信息图灵 → 元数据预验收；上机—
P4查询书目及编目数据图灵 → 元数据预验收；上机原编含查重
P5更新编目数据图灵 → 元数据预验收无编目经查国图联编路径
P6获取分类号最大种次号图灵 → 元数据预验收无编目或有编目无馆藏
P7新建或更新馆藏连接数据图灵 → 元数据预验收—
P8查询指定书目的馆藏数据图灵 → 元数据预验收；上机—
P9修改单册信息图灵 → 订单预验收虚拟；实际验收；分拣含修改单册条码号（实际验收）
P10新增订购日志图灵 → 订单预验收末；分拣交接新订购/单册日志
