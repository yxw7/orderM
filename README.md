# 图书馆采选订单管理系统 - 前端原型

TOB 图书馆采选订单管理系统前端页面，基于 Axure 原型转换生成，采用 HTML5 + Tailwind CSS v3 + 原生 JavaScript 实现。

## 目录结构

```
html/
├── index.html              # 入口页（跳转至订单列表）
├── pages/                  # 各功能页面（109+ 页面）
├── css/
│   └── global.css          # 全局补充样式
├── js/
│   ├── config.js           # 导航与路由配置
│   ├── layout.js           # 顶部导航 + 侧边栏布局
│   └── common.js           # 公共交互（标签、弹窗、分页等）
└── images/                 # 图片资源
```

## 使用方式

1. 直接用浏览器打开 `html/index.html` 或 `html/pages/01_01_非连续出版物订单-订单列表.html`
2. 无需后端服务，所有页面可离线浏览
3. 通过左侧导航栏切换各功能模块

## 页面模块

| 模块 | 主页面 | 说明 |
|------|--------|------|
| 01 订单管理 | `01_01_非连续出版物订单-订单列表.html` | 订单列表、订单行、新建/编辑/发订等 |
| 02 采访验收 | `02_01_验收单管理.html` | 验收单、逐条收货、批量验收、换退催缺 |
| 03 采访结算 | `03_01_待结算.html` | 待结算、已结算、结算失败处理 |
| 04 订户管理 | `04_01订户列表.html` | 订户列表、馆员列表 |
| 05 货币管理 | `05_01_货币信息.html` | 货币信息维护 |
| 07 设置 | `07_01_退换撤订原因参数.html` | 系统参数配置 |

子页面（弹窗/表单类）以编码前缀区分，如 `01_01_11_新建订单.html` 为订单管理下的新建订单弹窗。

## 技术说明

- **样式**：Tailwind CSS v3（CDN 引入），通过 class 控制布局与样式
- **布局**：深色顶部导航 + 左侧折叠菜单 + 白色内容区（参考系统截图）
- **交互**：标签切换、侧边栏折叠、检索区展开、分页、下拉菜单
- **已剔除**：Axure 导航栏、大纲、缩放控件、备注气泡、需求文案、埋点调试 JS

## 重新生成页面

```bash
node scripts/generate-pages.js
```

脚本从 `prototype/` 目录读取 Axure 原型，输出至 `html/pages/`。已手工精调的页面（如订单列表）在 `SKIP_FILES` 中排除，不会被覆盖。
