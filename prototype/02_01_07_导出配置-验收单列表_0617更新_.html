导出配置 ：纸质书

1 导出配置是用户级，不同用户设置不同

   1.1 导出文件格式 excel

   1.2 导出文件名称  验收单列表_时间戳

2 默认显示纸质书配置项，点击左侧音像资料文字链，切换到音像资料配置项

3 【纸质书】配置字段

     3.1  默认勾选上“全选”，导出字段视用户勾选结果

     3.2 下方excel截屏，是纸质书 勾选全部字段的示例图

     3.3 总码洋：（换算成人民币）

          一种书的码洋：套内册数是1 ，码洋= 定价 x 实收套数； 套内册数是>1 ，码洋= 定价 x 实收套数

          总码洋是所有书的码洋之和

     3.4 总实洋：（换算成人民币）

          一种书的实洋：套内册数是1 ，实洋= 实洋（收货弹实洋值） x 实收套数； 套内册数是>1 ，实洋= 实洋（收货弹实洋值） x 实收套数

          总实洋是所有书的实洋之和

     3.5 折扣率：供应商自带的

     3.6 总种数：按实收计算

     3.7 总册数：按实收计算。套内册数是1 ，套数=册数；套内册数是>1 ，册数=套内册数 X 套数
