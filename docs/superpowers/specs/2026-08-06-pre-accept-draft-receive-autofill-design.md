**日期**：2026-08-06  
**状态**：已评审待实现  
**模块**：采访验收 / 验收单管理 · 预验收；逐条收货  
**关联**：

- 修订：`2026-07-27-pre-accept-wizard-design.md`、`2026-07-27-pre-accept-batch-validation-alignment-design.md` 中与本期冲突的约定（套数＜待收记不一致、预验收不落库、批验收并列等）

## 1. 背景与目标

书商发货单格式不一，需先预验收核对差异并保存通过数据；真正收货仍在逐条收货中由馆员校对确认。批验收「校验通过即写入收货」与此流程冲突，本期去掉。

### 1.1 目标

- 验收单管理**仅保留预验收**；移除批验收入口
- 预验收支持**非首行表头**（点选表头行）+ 列映射 + 可保存映射模板（含表头行号）
- 系统标准字段按验收单 **资源类型 × 语种（中文/外文）** 四套展示
- 校验：`0 ＜ 收货套数 ≤ 待收` **不**因套数记失败；其它已映射字段不一致 → 失败
- **允许部分成功**：通过行写入该验收单下预验收草稿（覆盖同订单行）
- 失败行单独下载：原发货单列 + 失败原因
- 逐条收货打开收货窗时自动带入草稿中与收货窗对应的字段；确认收货后清除草稿

### 1.2 非目标

- 供应商固定模板包（无模板不可导入）——后续迭代
- 自动猜测表头行
- 批验收 / 导入即收货
- 异步导入任务
- 改造侧栏「批量验收」页
- 换货/退货页带入预验收

## 2. 方案

**改造现有预验收向导 + 验收单维度草稿存储（已选）**。

备选未采用：异步任务流；预验收增加第四步「确认导入」（多一步收益有限）。

## 3. 入口

| 条件 | 结果 |
|------|------|
| 已关联订户 + 勾选恰好 1 条未开始/进行中验收单 | 可打开预验收；打开前设为当前工作验收单 |
| 未关联订户 | `您没有关联订户，无操作权限` |

## 4. 向导步骤

```text
① 上传文件 → ② 字段映射（含表头行）→ ③ 解析文件 → 完成
```

### 4.1 上传

仅 `.xls` / `.xlsx`。通过后进入②。

### 4.2 字段映射

1. **表头所在行**：预览文件前 20 行，默认第 1 行；用户点选一行作为表头；该行作列名，其下为数据。  
2. **列映射**：文件列 → 系统标准字段（扁平下拉，无分组标签）；按验收单资源类型 + 语种切换字段池（见 §5）。  
3. **映射模板**：可选择/保存/更新/删除；模板保存 **表头行号 + 列映射**；与预验收 profile 绑定。应用模板时恢复二者。  

未选表头或必填未映完不可进入③。

### 4.3 解析文件

- 进度条 → 汇总「成功 X / 失败 X」  
- 允许部分成功；不要求全部通过才可完成  
- 有失败时展示「下载失败数据」  
- 「完成」：通过行写入草稿；关闭向导

## 5. 系统标准字段（四套）

语种：验收单语种为「中文」走中文池；其余语种一律走外文池。

### 5.1 纸质书 · 中文

**必填\***：订单行号、收货套数、套内册数、实洋、定价  

**可选**：正题名、ISBN、副题名、分卷号、分卷名、分类号、出版社、作者、出版年、版本、丛编、主题词、读者对象、装帧形式、尺寸、正文语种、卷数、出版地、一般性附注、图书简介、备注  

### 5.2 纸质书 · 外文

**必填\***：订单行号、收货套数、套内册数、实洋、定价  

**可选**：ISBN、学科大类、学科细分、中图分类号、中译名、题名、副题名、责任者、丛编、出版社、装帧形式、出版日期、版次、页数、币种、主题词、读者对象、尺寸、语种、简介、精简装ISBN对照、馆藏信息、审读级别、获奖信息、目次信息、分卷号、分卷名、作者简介、书评、备注  

### 5.3 视听资料 · 中文

**必填\***：订单行号、收货套数、套内件数、实洋、码洋  

**可选**：ISBN、ISRC、题名、载体、出版社、版本/格式、著者、币种、彩胶颜色、限量编号、厂牌、系列名称、是否签名、是否老唱片、获奖信息、北京出版社、分类、盘号、老唱片品牌、剧种、年代、备注  

### 5.4 视听资料 · 外文

**必填\***：订单行号、收货套数、套内件数、实洋、码洋  

**可选**：ISRC、题名、载体、商品条码、目录号、外文原文题名、出版方、币种、备注、厂牌

## 6. 校验规则

匹配池：关联订户下可收货订单行，且与验收单 **资源类型、语种（中/外分档）、采选方式、供应商** 一致。

### 6.1 套数

| 条件 | 结果 |
|------|------|
| 无法解析 / 空 | 数据错误 |
| ≤ 0 | 套数非法（`套数 ≤ 0`） |
| ＞ 待收 | 套数非法（`套数大于待收`） |
| **0 ＜ 套数 ≤ 待收** | **该维度通过**（不再因少于待收记不一致） |

### 6.2 其它已映射字段（除订单行号）

与订单行比对；不等 → **不一致**。金额两位小数；数量按数值。

### 6.3 其它类型

数据错误、未匹配、验收单不匹配 — 含义同既有逻辑。同行多种失败类型用 `；` 拼接。页面汇总：有任一失败类型计失败。

### 6.4 下载失败数据

仅失败行。列：**原发货单全部列（原顺序）+ 失败原因**（不含「校验结果」列）。Excel（.xls）格式延续现有导出方式。

## 7. 预验收草稿

| 项 | 约定 |
|----|------|
| 维度 | 验收单号 + 订单行号 |
| 内容 | 通过行的发货单已映射值（供收货窗带入） |
| 写入 | 「完成」时仅写入通过行；同订单行再次预验收 → **覆盖** |
| 清除 | 该订单行在逐条收货中**确认收货成功**后删除草稿 |
| 实现 | 前端 mock：localStorage 或模块内存；键含验收单号 |

全部失败时提示且不写草稿。有至少一条成功写入时：若验收单状态为未开始，则置为进行中。

## 8. 逐条收货带入

打开收货窗 / 合并处置面板「收货」页签时，若当前工作验收单下该订单行存在草稿，则预填：

| 收货窗控件 | 纸质书 | 视听资料 |
|------------|--------|----------|
| 收货套数 | 草稿收货套数 | 同左 |
| 定价 / 码洋 | 定价 | 码洋 |
| 实洋 | 实洋 | 实洋 |
| 套内册数 / 件数 | 套内册数 | 套内件数 |

无草稿则保持现有默认。用户可改后确认；确认收货成功 → 清除该行草稿。换货/退货不带入。

列表「预验收」标记：建议 P1，非本期必做。

## 10. 测试要点

1. 无批验收入口；预验收勾选与订户前置正确  
2. 表头非第 1 行：点选后列名/数据正确；模板恢复表头行号 + 映射  
3. 四套字段池与必填\*与 §5 一致  
4. `0 ＜ 套数 ≤ 待收` 不因套数失败；映射字段不一致失败；部分成功写入草稿  
5. 失败下载仅失败行：原列 + 失败原因  
6. 逐条收货带入对应字段；确认收货后草稿清除；再预验收同单行覆盖
