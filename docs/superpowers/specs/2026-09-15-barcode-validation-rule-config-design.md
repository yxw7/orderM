# 条码校验规则通用配置

**日期**：2026-09-15  
**状态**：已确认  
**模块**：设置 · 条码校验规则（新）  
**关联**：
- 现有「条码号供应商代码」（`/barcode-supplier`）— 馆配商代码段取值来源
- 订户「所属组织 → 所属机构」— 本功能「所属机构」选项同源
- 验收自动分配条码 / 初始条码校验 — **本期不接入**，仅预留校验与生成能力

---

## 1. 背景与目标

不同图书馆条码编码结构差异大：首都图书馆为固定 13 位、按条码类型（01～11）分段且部分规则含馆配商代码；园区馆为 `YQ` + 年份 2 位 + 流水 6 位（共 10 位）。现有系统缺乏可按机构配置的通用组成方式，无法同时表达本馆规则与外馆规则。

### 1.1 目标

1. 在「设置」中提供条码校验规则的增删改查与启停。
2. 按**所属机构**维护多条规则；每条含**规则代码**、**条码类型**、**总长度**与**有序分段组成方式**。
3. 组成方式足以覆盖首图 01～11 与园区馆等变长规则；支持后续校验与生成（本期配置页内预览即可）。
4. 馆配商代码段与现有「条码号供应商代码」配置联动（取值约定，业务接入时使用）。

### 1.2 非目标

- 不改造验收单、逐条收货、批量验收等业务中的条码分配/校验逻辑（后续迭代接入）。
- 不引入校验位算法、正则 DSL、馆代码独立段类型。
- 不新增「是否含馆配商代码」头字段（由是否配置馆配商段推导）。
- 不在本期做跨机构规则复制/导入导出。

---

## 2. 方案选型

**已选：有序分段积木式规则编辑器（总长度可变）**

| 方案 | 说明 | 结论 |
|------|------|------|
| A | 有序分段 + 规则级总长度；段类型固定/年/馆配商/流水/枚举 | **采用** |
| B | 模板字符串 DSL | 馆员难维护，否决 |
| C | 仅内置模板填参 | 外馆扩展差，否决 |

**过程中修正的假设**：

- 初版「每机构同时只启用一条」与首图 01～11 并存矛盾 → 改为**同机构多条规则可同时使用中**，启停粒度为「机构 + 规则代码」。
- 「馆代码」与「固定字符」语义重叠 → **去掉馆代码段**，`001`/`003`/`YQ`/`T` 等一律用固定字符。
- 「是否含馆配商代码」头字段多余 → **去掉**，有馆配商段即含供应商。

## 3. 信息架构与页面

### 3.1 入口

- 侧栏：设置 → **条码校验规则**（置于「条码号供应商代码」下方）
- 路由：`/barcode-rule`
- 代码目录：`html/src/modules/barcode-rule/`（对齐 `barcode-supplier` / `shortage-config`）

### 3.2 列表

**检索**：所属机构、条码类型、状态（全部 / 使用中 / 已停用）；可选规则代码。

**列**：序号、所属机构、规则代码、条码类型、组成摘要、总长度、状态、操作（创建人/创建日期可按现有设置页惯例附加）。

**组成摘要**：由分段生成只读文案，如 `固定001 | 固定T | 年份 | 馆配商 | 流水5`。

**操作**：

| 状态 | 可用操作 |
|------|----------|
| 使用中 | 编辑、停用 |
| 已停用 | 编辑、启用、删除 |

工具栏：**新增规则**。

### 3.3 新增/编辑弹窗

| 字段 | 必填 | 说明 |
|------|------|------|
| 所属机构 | 是 | 可搜索单选；选项同订户所属机构 |
| 规则代码 | 是 | 如 `01`、`02`；同机构唯一 |
| 条码类型 | 是 | 如「中文成人普通图书」；同机构不可重复 |
| 总长度 | 是 | 正整数；首图演示 13，园区 10 |
| 组成方式 | 是 | 有序分段表，至少 1 段 |
| 状态 | 是 | 使用中 / 已停用；新增默认可为使用中 |
| 备注 | 否 | 多行文本 |
| 样例 | 否 | 可手填或由预览生成，便于列表/详情核对 |

**分段表列**：序号、段类型、长度、参数、排序（上移/下移）、删除。  
**添加分段**按钮。  
**实时预览**：按当前分段与演示上下文拼接示例；展示「当前合计长度 / 总长度」。

## 4. 组成方式（分段模型）

### 4.1 段类型

| type | 名称 | 参数 | 说明 |
|------|------|------|------|
| `fixed` | 固定字符 | `value`（字符串） | `value.length` 必须等于段 `length`；用于馆前缀与类型标记（001/003/YQ/T/TG/D…） |
| `year` | 年份代码 | 可选 `format`，默认 `yy`（两位） | 段长通常为 2 |
| `supplier` | 馆配商代码 | 无（或预留位数说明） | 取值来自「条码号供应商代码」中对应条码号类型 + 供应商的条码号代码；**同一规则至多一段** |
| `serial` | 流水号 | `pad: true`（左侧补零） | 数字；位数 = 段长 |
| `enum` | 枚举代码 | `name` + `options[{ code, label }]` | 语种/载体/来源/地方文献 T·G 等；校验时 `code` 长度须等于段长 |

### 4.2 结构约束

1. 各段 `length > 0`；`sum(length) === totalLength`。
2. `fixed.value` 长度必须等于该段 `length`。
3. `supplier` 至多出现一次；原型演示按 2 位与现网供应商代码一致。
4. `enum.options` 非空；每个 `code` 长度等于段长且同段内 `code` 不重复。
5. 保存时若不满足上述约束，字段级或弹窗内提示，禁止提交。

### 4.3 示例

**首图 · 规则 02 · 中文成人普通图书（13）**

| # | 类型 | 长度 | 参数 |
|---|------|------|------|
| 1 | 固定字符 | 3 | `001` |
| 2 | 固定字符 | 1 | `T` |
| 3 | 年份代码 | 2 | yy |
| 4 | 馆配商代码 | 2 | — |
| 5 | 流水号 | 5 | 补零 |
| 样例 | | | `001T230002965` |

**园区馆（10）**

| # | 类型 | 长度 | 参数 |
|---|------|------|------|
| 1 | 固定字符 | 2 | `YQ` |
| 2 | 年份代码 | 2 | yy |
| 3 | 流水号 | 6 | 补零 |
| 样例 | | | `YQ24000001` |

**首图 · 规则 08 · 小语种（枚举）**：`001` + 语种枚举 2 位（TR/TJ/…）+ 年 2 + 流水 6。  
**首图 · 规则 10 · 成人视听**：`001` + 载体枚举 2 + 年 2 + 来源枚举 1 + 流水 5。

## 5. 业务规则

1. **唯一性**：同一 `institutionId` 下 `ruleCode` 唯一；同一机构下 `barcodeType` 不可重复。
2. **启停**：同机构多条规则可同时为「使用中」（覆盖首图多类型并存）。停用后不参与后续业务选用（本期无业务调用，仅状态展示）。
3. **删除**：仅「已停用」可删；使用中须先停用。
4. **馆配商联动**：规则含 `supplier` 段时，生成/校验上下文需提供供应商；代码从「条码号供应商代码」按条码类型与供应商解析。配置页预览可用 Mock 供应商代码（如 `00`）。
5. **列表「含供应商」**：若不单独列表列，可不展示；若展示则由是否存在 `supplier` 段推导，无独立存储字段。

## 6. 数据模型

```text
BarcodeRule {
  id: string | number
  institutionId: string
  ruleCode: string
  barcodeType: string
  totalLength: number
  segments: Segment[]
  status: 'active' | 'inactive'
  remark?: string
  sample?: string
  creator: string
  created: string   // 展示用日期
}

Segment {
  type: 'fixed' | 'year' | 'supplier' | 'serial' | 'enum'
  length: number
  value?: string                          // fixed
  format?: string                         // year, default 'yy'
  pad?: boolean                           // serial, default true
  name?: string                           // enum 显示名
  options?: { code: string, label: string }[]  // enum
}
```

**预留纯函数（配置预览与后续业务共用）**：

- `validateBarcode(rule, code, ctx) → { ok, message? }`
- `buildBarcode(rule, ctx) → string`  
  `ctx` 可含：`year`, `supplierCode`, `serial`, `enumValues` 等。

本期业务页面不调用；配置弹窗预览可调用 `buildBarcode`。

## 8. 错误与交互文案（配置侧）

| 场景 | 提示方向 |
|------|----------|
| 缺必填 | 请填写{字段} |
| 同机构规则代码重复 | 该机构下规则代码已存在 |
| 同机构条码类型重复 | 该机构下条码类型已存在 |
| 段长之和 ≠ 总长度 | 各分段长度之和须等于总长度 |
| 固定字符长度不符 | 固定字符长度须与分段长度一致 |
| 枚举 code 长度不符或重复 | 请检查枚举代码 |
| 删除使用中 | 请先停用再删除 |

启停/删除确认弹窗风格对齐「条码号供应商代码」。

## 9. 测试要点（原型）

1. 新增首图式 13 位规则与园区式 10 位规则均可保存；预览样例正确。
2. 段长之和错误、固定字符长度错误时无法保存。
3. 同机构重复规则代码 / 条码类型被拦截。
4. 使用中不可删；停用后可删；多条可同时使用中。
5. 含 `supplier` 段的规则预览能插入 Mock 馆配商代码；无该段的规则预览不依赖供应商。
6. 侧栏入口与路由标题正确；与「条码号供应商代码」页面互不覆盖。
