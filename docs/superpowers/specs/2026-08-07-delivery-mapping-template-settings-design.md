# 发货单映射模板配置（设置）设计

**日期**：2026-08-07  
**状态**：已确认，**暂缓实现**（后续单独排期；当前优先预验收既有规格）  
**模块**：设置 · 发货单映射模板；采访验收 / 预验收向导  
**关联**：
- 预验收映射交互：`2026-08-06-pre-accept-draft-receive-autofill-design.md`
- 修订既有「模板仅向导内保存、无独立管理页」及预验收固定桶 `预验收` 的约定（`2026-07-27-pre-accept-wizard-design.md`、`2026-06-23-delivery-note-import-acceptance-design.md` 中与本期冲突部分）
- **不**服务已废弃的发货单导入任务

---

## 1. 背景与目标

预验收依赖发货单列映射；模板此前仅在向导内按固定桶保存，无法按供应商 / 资源类型 / 语种 / 订户统一维护。需要在「设置」提供独立配置页，并与预验收向导**共用同一套模板数据**。

### 1.1 目标

- 设置新增「发货单映射模板」：按资源类型、语种、供应商、订户（可选）维护模板
- 列表支持新增、编辑、字段映射、删除
- 新增/编辑：资源类型、语种、供应商必填；订户非必填
- 字段映射：上传样例 Excel → 表头行号 → 列映射 +「是否校验」
- 预验收向导仍可选择 / 保存 / 更新 / 删除，读写同一扁平模板库

### 1.2 非目标

- 发货单导入任务 / 批验收模板
- 模板启停状态
- 自动猜测表头或原始文件预览
- 改造订单导入模板配置（另一产品）

---

## 2. 方案

**扁平模板库（方案 1）**：每条模板为完整记录（元数据 + 映射），设置页 CRUD；向导按当前验收单上下文筛选与写入。废弃「`supplier|type|lang` 分桶 + 预验收固定桶」作为主模型。

---

## 3. 入口与路由

| 项 | 约定 |
|----|------|
| 菜单 | 设置 →「发货单映射模板」（建议紧邻「订单导入模板配置」） |
| 路由 | `/delivery-mapping-template` |
| 页标题 | 发货单映射模板 |

---

## 4. 数据模型

| 字段 | 必填 | 说明 |
|------|------|------|
| `id` | 系统 | 唯一标识 |
| `name` | 是 | 模板名称；库内唯一，重名不可保存 |
| `resourceType` | 是 | `纸质书` / `视听资料` |
| `language` | 是 | 与验收单一致的**具体语种**（精确匹配） |
| `supplier` | 是 | 供应商名称 |
| `subscriber` | 否 | 空 = 该供应商下通配；有值 = 仅该订户可选 |
| `headerRow` | 映射后 | Excel 物理行号（从 1 起） |
| `columnMapping` | 映射后 | 文件列名 → 标准字段 key |
| `mustMatchFields` | 映射后 | 「是否校验」标准字段 key 列表（去重） |

- 同供应商 / 同订户**允许多条**模板（靠名称区分）。
- 标准字段池：与预验收一致，按 `resourceType × language（中文/外文归桶）` 四套。
- 存储：独立扁平列表（新 localStorage key 或重构现有模板 API）；旧「预验收」分桶可一次性迁入（缺元数据需补全）或演示环境用新样例覆盖。

### 4.1 向导选用规则

当前验收单可用模板须同时满足：

1. `resourceType`、`language`、`supplier` **精确匹配**
2. 模板 `subscriber` 为空 **或** 该订户属于当前验收单已关联订户集合

满足条件的可多条，向导下拉按名称选择。

---

## 5. 列表页

对齐「订单导入模板配置」：搜索 +「新增」+ 表格 + 分页。

**列**：模板名称、资源类型、语种、供应商、订户（空显示「全部」）、操作。

**搜索**：资源类型、语种、供应商、订户、模板名称（模糊）。

**操作**：

| 操作 | 行为 |
|------|------|
| 编辑 | 仅改元数据（§6） |
| 字段映射 | 进入映射页（§7） |
| 删除 | 确认后删除整条（含映射） |

空态：提示暂无模板，引导「新增」。

---

## 6. 新增 / 编辑（元数据）

弹窗表单。

| 字段 | 控件 | 校验 |
|------|------|------|
| 模板名称 | 文本 | 必填；库内重名不可保存 |
| 资源类型 | 单选：纸质书 / 视听资料 | 必填 |
| 语种 | 下拉（验收单语种列表） | 必填 |
| 供应商 | 下拉（供应商主数据） | 必填 |
| 订户 | 下拉，可清空 | 非必填；空 = 通配 |

- **新增**：只建元数据；映射可为空，可稍后「字段映射」完善。
- **编辑**：只改上表；不改已有 `headerRow` / `columnMapping` / `mustMatchFields`。
- 若编辑导致资源类型或语种变化：保存时**保留仍合法的映射项**，剔除非法标准字段及其「是否校验」项，并提示「已按新类型/语种清理无效映射」。

---

## 7. 字段映射页

入口：列表「字段映射」。全页或大弹层；交互对齐预验收第 2 步。

1. 上传样例 `.xls` / `.xlsx`
2. 表头行号 +「读取表头」（不自动读取）
3. 列映射：文件列名 → 标准字段（按本模板资源类型×语种）+「是否校验」
4. **保存**：写入 `headerRow`、`columnMapping`、`mustMatchFields`；**点击保存时**才校验必填标准字段是否已映射（未齐则提示并停留）
5. **取消**：不落库

「是否校验」规则与预验收一致（订单行号、收货套数等不可勾选等既有约束沿用）。

---

## 8. 预验收向导联动

两处共用同一扁平库。

| 能力 | 行为 |
|------|------|
| 选择 | 仅列出 §4.1 可用模板；选用后恢复表头行号 + 列映射 + 是否校验；仍须用户对当前文件点「读取表头」 |
| 保存模板 | 输入名称；自动带入验收单资源类型 / 语种 / 供应商；**订户默认空（通配）**；写入同一库 |
| 更新模板 | 覆盖当前选中模板的映射三件套；**不**改元数据 |
| 删除模板 | 删除库中该条 |

向导第 2 步必填映射校验时机仍为点击「下一步」（见预验收修订规格）。

---

## 9. 错误与边界

| 场景 | 处理 |
|------|------|
| 元数据缺必填 / 重名 | 表单内提示，不保存 |
| 映射保存时必填未齐 | 提示「请映射「{字段}」」，不关闭 |
| 样例非 xls/xlsx | 提示支持类型 |
| 表头行号无效或变更未再读 | 不可保存映射 / 与向导一致拦截 |
| 删除 | 二次确认 |
| 向导上下文无匹配模板 | 下拉为空，可手工映射后「保存模板」新建 |

---

## 10. 验收要点

1. 设置菜单可见「发货单映射模板」，可 CRUD 元数据
2. 字段映射上传样例后可保存 header + 映射 + 是否校验
3. 订户空显示「全部」；指定订户后仅当该订户属于验收单已关联订户时向导可选
4. 同供应商可多条；向导按 §4.1 筛选
5. 向导保存的模板出现在设置列表，且维度正确
6. 编辑改类型/语种后非法映射被清理并提示
7. 发货单导入任务不在本期改动范围

---

## 11. 决策摘要

| 项 | 结论 |
|----|------|
| 服务对象 | 仅预验收 |
| 与向导关系 | 共用数据；向导保留选/存/更/删 |
| 存储 | 扁平一条一记录 |
| 语种 | 具体语种，精确匹配 |
| 订户空 | 供应商通配；指定则仅该订户 |
| 同维度多模板 | 允许 |
| 编辑 vs 字段映射 | 元数据 / 样例映射分离 |
| 映射列来源 | 上传样例 Excel |
| 必填映射校验 | 点保存（设置）/ 点下一步（向导） |
