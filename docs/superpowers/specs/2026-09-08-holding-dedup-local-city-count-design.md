# 馆藏重复本馆/全市计数与查重结果单件展示

**日期**：2026-09-08  
**状态**：已确认  
**模块**：订单行列表查重结果（5.3.5.6）；书目 / 单件页签  
**关联 / 修订**：
- 承接 `2026-09-08-subscriber-embedded-permission-org-design.md` 中「查重结果面板交互」后续项
- 修订 `docs/prd.md` 5.3.5.6：废除「匹配到馆藏书目即有」；列表馆藏重复改为「有/无（本馆/全市）」
- 修订单件页签列序与全市展示；馆藏树一～三级与单件列表按关联订户所属组织机构（机构→馆区→分馆）合集去重优先排序；书目页签单件数量列位与格式

## 1. 背景与目标

现状：订单行「馆藏重复」仅显示「有 / 无」；有重复判定为「匹配到馆藏书目即有」，与单件数量无关；书目页签「单件数量」在单选后首列且展示「N本」；单件页签列含所在馆/所在馆藏地/登到时间，树一级默认「首都图书馆」置顶，展示侧曾以查重范围内单件为准。

产品要求：

1. 列表「馆藏重复」展示本馆/全市单件数，并按本馆单件数判定有/无；全市非 0 可打开查重结果面板。
2. 单件页签展示全市单件，调整列序并增加借阅次数；馆藏树一～三级节点与单件列表按关联订户所属组织机构（机构→馆区→分馆）合集去重优先排序。
3. 书目页签「单件数量」改为 `本馆/全市`，并移到书目记录号之后。

### 1.1 目标

1. **本馆口径统一**：本馆单件数 = 当前用户关联订户的所属机构合集（去重）内单件数；与「查重范围单件数」同一口径，用于有/无判定。
2. **列表可扫读**：`有（本馆/全市）` / `无（本馆/全市）`；`无（0/0）` 不可点；筛选仍按有/无。
3. **面板一致**：书目行与列表共用本馆/全市计数契约；单件列表全市可见；借阅次数只读展示。
4. **展示优先序**：馆藏树一～三级与单件列表均按关联订户所属组织机构合集（去重保序）优先；取消「首都图书馆」特殊置顶。
5. 同步 `docs/prd.md`（5.3.5.6 及必要交叉引用）与订单查重前端原型 / PRD 抽屉数据。

### 1.2 非目标

- 订户新增/编辑、所属组织机构配置（已另立规格）
- MARC 信息页签、订单页签交互改造
- 借阅次数中台对接协议细项、更新调度实现（本版约定来源与空值展示即可）
- 订单重复列（保持「有 / 无」）

## 2. 方案选型

**已选：方案 A — 一次改完 + 明确计数契约**

| 项 | 说明 |
|----|------|
| 订单行 | 落库/回写 `holdingLocalItemCount`、`holdingCityItemCount`、`holdingDuplicate` |
| 书目结果行 | 每条带 `localItemCount`、`cityItemCount` |
| 单件 | 返回全市单件；含 `loanCount`（可空） |

未选：前端现算本馆/全市（载荷重、筛选易不一致）；分三期交付（中途口径分裂）。

## 3. 订单行列表 · 馆藏重复列

### 3.1 本馆机构集合

1. 取当前馆员**关联订户**列表（保持既有顺序）。
2. 收集各订户所属机构（`institutionId`），**去重且保序**（编码首次出现保留）。
3. 单件是否计入本馆：该单件所属馆所属机构 ∈ 上述集合。

### 3.2 有 / 无判定（变更）

| 条件 | 馆藏重复文案前缀 |
|------|------------------|
| `holdingLocalItemCount > 0` | 有 |
| `holdingLocalItemCount = 0`（已做馆藏查重） | 无 |

**废除**：匹配到馆藏书目即「有」（与单件数量无关）。

未做馆藏查重：列仍为**空白**（`holdingDuplicate` 为空），与现网一致。

### 3.3 展示与点击

展示格式：`有（holdingLocalItemCount/holdingCityItemCount）` 或 `无（holdingLocalItemCount/holdingCityItemCount）`。

| 示例 | 可否打开查重结果面板 |
|------|----------------------|
| `有（10/50）` | 是 |
| `无（0/50）` | 是 |
| `无（0/0）` | 否（非文字链，纯文本） |
| 空白（未查重） | 否 |

- 可点击条件：**全市单件数 ≠ 0**（即 `holdingCityItemCount > 0`）。
- 打开后：统一查重结果面板，默认页签仍为**书目**（与现「有」入口一致）。
- **订单重复**：仍为「有 / 无」文字链规则，本版不变。

### 3.4 筛选

- 筛选项仍为：**全部 / 有 / 无**，默认全部。
- 「有」匹配 `holdingDuplicate === true`；「无」匹配 `holdingDuplicate === false`；空白（未查重）不匹配「有」或「无」。
- 筛选**不解析**括号内数字。

## 4. 查重结果面板

### 4.1 书目页签

- 列顺序：**单选 → 书目记录号 → 单件数量（本馆/全市） → 其余书目字段 → 操作**。
- 列名固定为「**单件数量（本馆/全市）**」；单元格文案：`localItemCount/cityItemCount`（如 `10/50`）；**不再**使用「N本」。
- 书目字段随资源类型与语种动态切换；统一列名「**题名**」（不再用「正题名」）；题名后固定增加：**分卷号**、**分卷名**（空值「—」）；**不展示副题名**；关联/取消关联、分页规则不变。

### 4.2 单件页签

- **显示范围**：当前单选书目下的**全市**单件；左侧馆藏树过滤逻辑不变（未选叶子显示全部；选叶子过滤）。
- **优先序数据源**（树与单件共用）：见 §5.5「所属组织机构优先合集」。
- **馆藏树排序（一～三级）**：
  - 一级（机构）：按优先合集中的机构序靠前；未命中优先列表的保持其原相对序排在后面；**取消**「首都图书馆」特殊置顶。
  - 二级（馆区）：在同一父节点下，按优先合集中的馆区序靠前；未命中排后；**不跨父节点搬迁**。
  - 三级（分馆）：在同一父节点下，按优先合集中的分馆序靠前；未命中排后；**不跨父节点搬迁**。
  - 四级（馆藏地）及「未关联馆藏地」叶子：本版不按组织机构优先重排；一级根「未关联馆藏地」仍排在一级末尾。
- **单件列表排序**：按单件所属组织路径映射到优先合集排序（优先匹配分馆 → 否则馆区 → 否则机构）；同优先键内保持过滤后的原相对序；无法映射的排在最后。树叶子过滤后的子集仍套用同一规则。
- **列顺序**（12 列）：
  1. 馆藏状态  
  2. 条码号  
  3. 所属馆  
  4. 所属馆藏地  
  5. 借阅次数（`loanCount`）  
  6. 卷册描述  
  7. 单件价格  
  8. 借阅类型  
  9. 装帧  
  10. 索书号  
  11. 排架标引分类  
  12. 排架标引  
- **删除列**：所在馆、所在馆藏地、登到时间。
- **借阅次数**：由外部接口提供；数据中台约每月更新一次借阅量；空值展示「—」。

### 4.3 不变

- MARC 信息页签、订单页签
- 面板高度、摘要区、页签顺序（书目 → MARC → 单件 → 订单）
- 自动关联书目规则（仍在查重返回落库时处理）

## 5. 数据契约与汇总

### 5.1 书目结果行

| 字段 | 类型 | 含义 |
|------|------|------|
| `localItemCount` | number | 该书目下、所属机构 ∈ 本馆集合的单件数 |
| `cityItemCount` | number | 该书目下全市单件数 |

约束：`localItemCount ≤ cityItemCount`；皆为非负整数。

### 5.2 订单行回写（馆藏查重完成后）

| 字段 | 类型 | 含义 |
|------|------|------|
| `holdingLocalItemCount` | number | Σ 各命中书目 `localItemCount` |
| `holdingCityItemCount` | number | Σ 各命中书目 `cityItemCount` |
| `holdingDuplicate` | boolean \| null | `holdingLocalItemCount > 0` 为 true；已查且本馆为 0 为 false；未查为 null |

无命中书目时：两计数为 0，`holdingDuplicate = false`，展示 `无（0/0）`。

### 5.3 查重范围 vs 展示计数

- **检索命中**：仍按订户「所属组织机构」合并后的范围检索馆藏（决定哪些书目进入结果；可为机构/馆区/分馆，规则见订户规格与 5.3.5.5）。
- **有/无与括号「本馆」数字**：一律按 §3.1 **所属机构合集**统计单件，**不**按馆区/分馆进一步收窄。产品口中的「查重范围单件数」与本馆单件数同口径，均指该机构合集。
- **展示**：单件列表与全市数字按**全市单件**计算与展示，不再将展示侧裁成「仅检索范围内单件」。

### 5.4 借阅次数

- 单件字段 `loanCount`（number，可空）。
- 原型可 mock；生产由外部接口/中台供给；本版不定义中台 API 路径。

### 5.5 所属组织机构优先合集（树一～三级 + 单件列表）

取当前馆员**关联订户**列表（保持既有顺序），按订户依次合并下列有序编码，**全局首次出现保留**（去重保序）：

| 合集 | 来源字段 | 对应馆藏树层级 | 空值 |
|------|----------|----------------|------|
| `priorityInstitutionIds` | 订户 `institutionId` | 一级 · 机构 | 订户无机构机构则跳过（正常订户必有） |
| `priorityCampusIds` | 订户 `campusId` | 二级 · 馆区 | 未选馆区则不加入 |
| `priorityBranchIds` | 订户 `branchId` | 三级 · 分馆 | 未选分馆则不加入 |

说明：

- 与 §3.1「本馆机构集合」可共用机构去重保序结果；本馆**计数**仍只看机构，**不**因馆区/分馆收窄。
- 优先合集**仅用于**查重结果单件页签的树一～三级排序与单件列表排序；四级馆藏地不入合集。
- 合集皆空（无关联订户或无有效组织）：树与单件不额外重排，保持构建后的原相对序（仍无首都图书馆特殊置顶）。
- 节点/单件与编码的映射：通过馆藏主数据（机构/馆区/分馆编码或稳定名称）对齐；无法映射视为未命中优先列表。
