同步点清单 P1–P10 / A1–A6

P4 为新增「查单册」；其后编号顺延。原编落库不在接口同步点内。

#阶段同步点方向说明
P1预验收查订单行图灵 → 订单供差异对比
P2预验收按批次生成预验收图灵 → 订单含虚拟单册 + 虚拟条码
P3预验收推占位单册订单 → 编目待实际验收更新
P4预验收按书目记录号查单册列表及信息图灵 → 编目新增；在书目查重前
P5预验收查编目 / 书目查重图灵 → 编目是否已编目
P6预验收更新编目图灵 → 编目仅更新走接口；原编落库不通过接口
P7预验收分类号最大种次号图灵 → 编目补空号或新增
P8预验收新增和更新馆藏连接图灵 → 编目新增与更新
P9预验收查询馆藏连接索书号图灵 → 编目查询
P10预验收新增订购和单册日志图灵 → 编目不回写订单
A1实际验收原编后再查 / 分配图灵 → 编目仅原编分支
A2实际验收多卷查新订单人工订单 → 图灵 → 订单手工拆单后回填
A3实际验收条码查重图灵 → 编目条码是否已被使用
A4实际验收完成收货图灵 → 订单关单自动
A5实际验收再推单册订单 → 编目覆盖虚拟占位
A6实际验收新增订购和单册日志图灵 → 编目不回写订单
