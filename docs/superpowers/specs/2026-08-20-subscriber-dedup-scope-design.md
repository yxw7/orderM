## 1. 背景与目标

馆藏查重的「所属分馆 / 所属馆藏地」目前在查重配置弹窗（`DedupConfigModal`）中每次临时选择，不利于按业务订户固化范围，也无法表达「单件优先展示所属馆」的排序诉求。订户编辑弹窗字段已偏多，且其中多项本质为权限/范围配置，不宜继续堆在基本信息里。

### 1.1 目标

1. **拆分订户 UI**：基本信息与权限配置分离。
2. 将所属馆、资源类型、预算名称、条码号类型及馆藏查重范围迁入**权限配置**弹窗。
3. 已选查重分馆支持**全量优先级排序**（固定高度滚动 + 搜索）；顺序即优先展示所属馆。
4. 调用馆藏查重时，按**当前馆员关联订户**合并后的分馆/馆藏地检索有无馆藏单件。
5. 查重结果「单件」页签：左侧馆藏树一级节点与右侧单件列表均按优先所属馆排序。
6. 查重弹窗**删除**整块「查重范围」UI。

### 1.2 非目标

- 真实编目检索接口实现细节（原型 mock；请求/存档须带合并后的范围字段）
- 改造订单查重比对逻辑（仍按现有订户可见订单行规则）
- **数据归属**页签的业务实现（本版仅占位预览）
- 订单行详情、书目浮动窗等其它单件列表的排序（本版仅查重结果面板）
- 订户列表新增展示列（配置仍在弹窗内维护）

## 2. 方案选型

**已选：列表独立「权限配置」+ 弹窗内页签（线框 B+1 修订版）**

| 入口 | 内容 |

## 3. 基本信息弹窗

- 组件：现有 `SubscriberFormModal`（新增/编辑）**瘦身**。
- 字段仅保留：**订户名称**（必填）、**备注**。

- 新增订户：可先保存基本信息，再点「权限配置」补全；或产品约定新增成功后引导打开权限配置（实现时二选一，默认：保存后列表出现「权限配置」，不强制向导）。

## 4. 权限配置弹窗

### 4.1 入口与壳子

- 订户列表操作列增加 **「权限配置」**（与编辑并列）。
- 标题：`权限配置 — {订户名称}`；宽度约 `max-w-3xl`；底部取消 / 保存。
- **页签顺序**（默认「业务范围」）：
  1. **业务范围**
  2. **查重范围**
  3. **数据归属**（预览占位，本版不实现表单）
- 保存：一次提交**业务范围 + 查重范围**已编辑数据；切到「数据归属」不阻塞保存；数据归属无字段可提交。

### 4.2 页签：业务范围

| 字段 | 说明 |
|------|------|
| 所属馆 | 原订户表单字段；单选；可空（规则与现网一致） |
| 资源类型 | 必填；多选 |
| 预算名称 | 必填；多选 |
| 条码号类型 | 必填；多选 |

校验规则与迁移前订户表单一致（仅换入口）。

### 4.3 页签：查重范围

| 字段 | 存储键 | 控件 | 规则 |
|------|--------|------|------|
| 所属分馆 | `dedupBranchCodes: string[]`（**有序**） | `SearchableMultiSelect` + 已选排序区 | 选项同现查重弹窗（使用中四级分馆）；展示「编码 \| 名称」；可空；可多达数十个 |
| 所属馆藏地 | `dedupCollectionCodes: string[]` | `SearchableMultiSelect` | 已选分馆 → 下级馆藏地并集；未选分馆 → 全部馆藏地；变更分馆后剔除无效项；可空 |

**优先级 UI（已选分馆很多时）**

- 不另选优先馆集合；`dedupBranchCodes` 下标越小越优先。
- 已选分馆以有序列表展示：**固定最大高度 + 纵向滚动**；支持按编码/名称**搜索过滤**后上移/下移；过滤不改变未展示项的相对顺序，仅对当前可见项调序时写回全量数组（实现须保持全量顺序一致性）。
- 默认上移/下移；拖拽为可选增强，非必须。

**校验**

- 两字段均可空（该订户空配置 = 不限制该订户侧范围贡献）。
- 不强制「配置了分馆必须配置馆藏地」。
- 分馆停用：编辑时保留已选项展示。

### 4.4 页签：数据归属

- **本版仅占位**：文案说明「预览页签 · 后续实现」。
- 不收集字段、不参与保存校验。
- 页签可见，便于后续扩展入口固定。

### 4.5 查看订户

- 详情中只读展示业务范围与查重范围（可同页签结构或折叠区）；数据归属显示「暂未配置/敬请期待」即可。

## 5. 查重弹窗与请求合并

### 5.1 弹窗变更（`DedupConfigModal`）

- **删除**「查重范围」整块（所属分馆、所属馆藏地及 `showBranchScope` 相关逻辑）。
- 仅保留：重复类型、查重字段。
- 弹窗提交**不再**由用户选择 `branchCodes` / `collectionCodes`。

### 5.2 合并算法

查重提交前，取当前馆员**关联订户列表**（与现有可查看/关联订户同一数据源，**保持列表既有顺序**），计算：

1. **`branchCodes`（有序）**：按订户顺序依次拼接各订户 `dedupBranchCodes`；同一分馆编码**首次出现保留**（全局优先序）。
2. **`collectionCodes`（并集）**：各订户 `dedupCollectionCodes` 去重并集（顺序不敏感）。
3. 若合并后两数组皆空 → **不限范围**（与现弹窗未选一致）。
4. 仅当重复类型为「不限」或「馆藏查重」时将范围带入馆藏检索；「订单查重」不传范围。

### 5.3 请求与落库

- 馆藏查重调用携带合并后的 `branchCodes`（有序）、`collectionCodes`。
- 原型：写入订单行 `lastDedupBranchCodes` / `lastDedupCollectionCodes`；mock 可按范围裁剪或仅存档。

### 5.4 边界

- 馆员无关联订户：沿用现有权限提示；若仍进入查重，范围按空（不限）。
- 单行与批量查重：均使用「关联订户合并」规则（不按各订单行所属订户分别取配置）。

---

## 6. 查重结果排序（单件页签）

使用本次合并得到的有序 `branchCodes` 作为优先所属馆（可回落读取行上 `lastDedupBranchCodes`）。

| 区域 | 规则 |
|------|------|
| 左侧馆藏树 | 一级「机构/所属馆」节点按优先序靠前；不在优先列表中的馆排在后面（保持其原相对顺序稳定） |
| 右侧单件列表 | 按单件「所属馆」映射到分馆优先序；同馆内保持原相对顺序；未匹配优先列表的排后 |

- 所属馆与 `branchCodes` 的对应：通过馆藏主数据（分馆编码/名称）映射；无法映射的视为「未在优先列表」。
- 先按四级叶子（或未关联馆藏地）过滤，再排序。
- 优先序为空：不额外重排，保持原序。

## 7. 组件与数据流

| 位置 | 变更 |
|------|------|
| `SubscriberListView` | 操作列增加「权限配置」 |
| `SubscriberFormModal` | 仅名称、备注 |
| 新 `SubscriberPermissionModal`（或等价） | 三页签：业务范围 / 查重范围 / 数据归属占位 |
| `SubscriberDetailModal` | 只读展示业务范围 + 查重范围 |
| `subscriber-manage.js` | 保留既有权限字段；增加 `dedupBranchCodes`、`dedupCollectionCodes`；示例数据补齐 |
| `resolveLibrarianDedupScope()` | 关联订户合并分馆优先序 + 馆藏地并集 |
| `DedupConfigModal` | 删除查重范围 |
| `order` store `submitDedup` | 提交前合并范围并传入查重 |
| `DedupResultDrawer` | 树一级节点与单件列表按优先序排序 |
| PRD | 订户拆分、5.3.5.5、5.3.5.6 |

**数据流**：权限配置保存分馆序与馆藏地 → 馆员查重（弹窗只选类型/字段） → 确定时按关联订户合并范围 → 馆藏检索带范围 → 结果面板按分馆优先序展示树与单件。

## 8. 验收要点

1. 基本信息弹窗仅名称、备注；列表有「权限配置」入口。
2. 权限配置三页签：业务范围、查重范围可编辑保存；数据归属为占位。
3. 查重分馆可多选至数十个；排序区可滚动、可搜索、可上移/下移。
4. 查重弹窗无「查重范围」。
5. 多订户关联：馆藏地并集，分馆顺序按订户顺序拼接去重。
6. 结果面板馆藏树一级节点与单件列表按优先分馆靠前。
7. 各关联订户查重范围皆空 → 不限范围。
