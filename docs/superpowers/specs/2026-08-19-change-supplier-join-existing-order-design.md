## 1. 背景与目标

更换供应商时，迁出套数除可生成新发订订单外，还应支持**加入已有待发订订单**。行内与工具栏批量两个弹窗交互一致。

### 1.1 目标

- 弹窗顶部单选：**新建订单** / **加入订单**（默认「新建订单」）
- **新建订单**：按当前订单行信息 + 弹窗内容新建 1 条待发订订单及新订单行（延续现有逻辑）
- **加入订单**：通过单选可搜下拉选择目标待发订订单，向其追加新订单行（不新建订单头）
- 行内弹窗保留套数字段；工具栏批量仍无套数（各行按可迁出全量迁出）

### 1.2 非目标

- 改造催缺管理「更换供应商」
- 复用书目查询「加入订单」大表格弹窗
- 真实后端接口

---

## 2. 方案

**共享数据层 + 两弹窗扩展（已选）**

- 新增 `getChangeSupplierJoinOrderCandidates` 等纯函数，集中候选筛选与提交分支
- `OrderLineChangeSupplierModal.vue`、`BatchChangeSupplierModal.vue` 共用字段布局与 `SearchSelect` 选单组件
- `order` store 增加「加入已有订单」提交路径，或扩展现有 `changeSupplierGenerateOrder` / `batchChangeSupplierGenerateOrder` 的 `targetMode` 分支

## 3. 弹窗 UI

### 3.1 顶部单选

| 选项 | 说明 |
|------|------|
| 新建订单 | 默认选中 |
| 加入订单 | 选择后「订单名称」变为目标订单下拉 |

切换模式时：清空订单名称 / 已选目标订单；供应商、预算、原因、备注保留。

### 3.2 字段（两种模式字段集合相同，控件不同）

| 顺序 | 字段 | 新建订单 | 加入订单 |
|------|------|----------|----------|
| — | 流转摘要（仅行内） | 发订/已收/已换/已退套数只读 | 同左 |
| 1 | 供应商 | 必填；默认关联订单供应商；按采选方式过滤 | 同左；**参与目标订单筛选** |
| 2 | 预算名称 | 条件必填；默认关联订单预算 | 同左；**参与目标订单筛选** |
| 3 | 订单名称 | 文本；默认 `{原名}-{max+1}`；≤50 字；提交不校验重名 | **单选可搜下拉**；展示 `订单名称（订单号）`；值为 `orderId` |
| 4 | 套数 | 行内必填，默认可迁出，1～可迁出 | 同左 |
| 5 | 原因 | 必填；撤订原因参数（使用中） | 同左 |
| 6 | 备注 | 非必填；提交时追加至原订单行备注后写入目标发订备注 | 同左 |

**工具栏批量弹窗**：无套数字段；其余与上表一致（加入模式仍含供应商、预算、订单名称下拉、原因、备注）。

## 4. 加入订单 — 候选筛选

目标订单须**同时满足**：

1. 发订状态 = **待发订**（`orderStatus = pending`）
2. 订户 ∈ 当前馆员**可查看订户范围**（`getCurrentViewableSubscribers()`）
3. **资源类型、语种、采选方式**与源订单行一致  
   - 行内：当前行关联订单 + 行上字段  
   - 批量：勾选行首行关联订单维度（与批量启用条件中资源类型/语种/采选方式口径一致；**不要求同一 orderId**）
4. **供应商** = 弹窗所选供应商
5. **预算名称** = 弹窗所选预算；交换/捐赠预算可空时，仅匹配预算也为空的待发订订单

**交互**

- 供应商或预算变更 → 清空已选目标订单，重算下拉候选
- 无候选：字段下方提示「暂无符合条件的待发订订单，请调整供应商或预算」
- 馆员无关联订户：打开弹窗时提示（文案对齐书目「加入订单」），不阻断新建模式时可仅限制加入模式——实现时若两种模式共用打开入口，加入模式切换时再校验亦可

---

## 5. 提交数据流

### 5.1 新建订单（延续现逻辑）

1. 校验表单与可迁出套数（行内）/ 每行可迁出 ≥1（批量）
2. 新建 1 条待发订订单头（弹窗覆盖名称/供应商/预算/备注等）
3. 新建 N 条订单行；原行撤订段 += 迁出套数，原因 = 弹窗原因
4. 成功确认：  
   - 行内：「已生成新订单 {orderId}，原行对应套数已撤订，是否立即查看？」  
   - 批量：「已生成新订单 {orderId}，订单行种数 {种}，套数 {套}，册数 {册}，是否立即查看？」

### 5.2 加入订单

1. 校验表单 + 已选 `targetOrderId` 仍满足 §4 筛选
2. **不**新建订单头；向目标订单追加 N 条新订单行：  
   - 套数 = 行内填写套数 / 批量该行可迁出套数  
   - 供应商、预算、馆址等取自**目标订单抬头**  
   - 书目字段自原行复制；行状态待发订；是否催缺 = 否  
   - 备注：若弹窗填写备注，则追加至**源订单行**备注之后；未填写则不改动；新建/加入的目标订单不写此备注
3. 重算目标订单种数/套数/册数/码洋
4. 原行撤订回写同 §5.1
5. 成功确认：  
   - 行内：「已加入订单 {orderId}，原行对应套数已撤订，是否立即查看？」  
   - 批量：「已加入订单 {orderId}，订单行种数 {种}，套数 {套}，册数 {册}，是否立即查看？」

## 6. 校验与异常

| 场景 | 处理 |
|------|------|
| 加入模式未选目标订单 | 「请选择待发订订单」 |
| 所选订单不再待发订或不匹配筛选 | 「目标订单不可用，请重新选择」 |
| 套数非法（行内） | 「请填写合法套数（1～可迁出）」 |
| 未选供应商 / 原因 / 应填预算 | 字段下方红色提示 |
| 批量某行可迁出 = 0 | 报错中止，不部分成功 |
| 无可选撤订原因 | 原因下拉禁用并提示配置 |
