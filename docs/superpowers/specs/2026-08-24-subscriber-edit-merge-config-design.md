# 订户列表去掉配置 · 编辑合并业务与查重范围

**日期**：2026-08-24  
**状态**：已确认  
**模块**：订户管理（5.9）、馆藏查重范围文案（5.3.5.5）  
**关联 / 修订**：
- 修订 `2026-08-20-subscriber-dedup-scope-design.md`：取消独立「配置」弹窗与页签拆分；查重范围并回新增/编辑表单
- 本版**不做**所属分馆排序 UI；**不做**数据归属（含占位）

---

## 1. 背景与目标

先前将订户「基本信息」与「权限配置」拆成两个入口，列表增加「配置」。产品决定撤回该拆分：列表去掉配置；编辑/新增按既有编辑订户截图回填业务字段，并在同一弹窗用灰色分割线区分查重范围。

### 1.1 目标

1. 订户列表操作列**删除「配置」**。
2. **新增 / 编辑**使用同一完整表单弹窗（字段对齐截图 + 查重区块）。
3. 查重范围用**上下灰色横线**与上方业务字段区分；内含所属分馆、所属馆藏地（可搜索多选）。
4. **去掉**所属分馆排序（顺序区、搜索过滤、置顶/上移/下移/置底）。
5. **数据归属**本版不实现、不占位（列表/编辑/详情均无入口）。
6. 同步 PRD / 查重入口文案：范围来自订户编辑中的查重范围，不再写「配置」。

### 1.2 非目标

- 数据归属业务与占位页签
- 所属分馆优先序维护 UI
- 改造查重结果树 / 单件可配排序（沿用现有 5.3.5.6）
- 改造查重配置弹窗交互（仍不在弹窗内选范围）

---

## 2. 方案选型

**已选：单表单合并（方案 A）**

| 入口 | 内容 |
|------|------|
| 列表「新增」「编辑」 | 同一弹窗：业务字段 + 灰线夹住的查重范围 |
| 列表「配置」 | **删除** |
| 查看详情 | 无数据归属；无分馆顺序展示 |

未选：编辑内嵌页签（与「灰线区分」决策不符）；保留独立配置入口。

---

## 3. 列表

- 操作列：编辑、停用/启用、删除（与现逻辑一致）。
- 删除「配置」按钮及 `SubscriberPermissionModal` 挂载与提交链路。
- 点订户名称仍打开查看详情。

---

## 4. 新增 / 编辑弹窗

- 组件：扩展现有 `SubscriberFormModal`（或等价合并实现）；标题「新增订户」/「编辑订户」。
- 宽度建议不低于截图观感（约 `max-w-lg`～`max-w-xl`）；内容区可纵向滚动；底栏取消 / 提交（新增）或取消 / 保存（编辑）。

### 4.1 字段顺序与校验

| 顺序 | 字段 | 必填 | 控件 |
|------|------|------|------|
| 1 | 订户名称 | 是 | 文本，规则同现网（唯一、长度） |
| 2 | 单件所属馆 | 是 | 可搜索单选（使用中分馆；展示编码 \| 名称） |
| 3 | 资源类型 | 是 | 多选 |
| 4 | 预算名称 | 是 | 多选 |
| 5 | 条码号类型 | 是 | 多选 |
| 6 | 备注 | 否 | 多行文本，长度同现网 |
| — | （上灰线） | — | `border-top` 灰色实线 |
| 7 | 所属分馆 | 否 | `SearchableMultiSelect`；空 = 不限 |
| 8 | 所属馆藏地 | 否 | `SearchableMultiSelect`；空 = 不限 |
| — | （下灰线） | — | 灰色实线，闭合查重区块 |

查重区块顶可附一句弱提示：「查重范围 · 未选分馆/馆藏地视为不限」（非必填说明即可）。

### 4.2 查重范围规则（无排序 UI）

- 存储键保持：`dedupBranchCodes: string[]`、`dedupCollectionCodes: string[]`。
- **不提供**所属分馆顺序维护 UI；多选组件写入顺序即为数组顺序，本版不另做调序。
- 已选分馆 → 馆藏地选项为下级并集；未选分馆 → 全部馆藏地；变更分馆后剔除无效馆藏地。
- 不强制「选了分馆必须选馆藏地」；分馆停用时编辑仍保留已选项展示。

### 4.3 保存

- 一次提交：名称、备注、业务字段、查重两字段。
- 校验失败停留弹窗并提示（必填「请选择」/ 名称规则同现）。

---

## 5. 查看订户详情

- **删除**「数据归属」页签。
- **删除**「所属分馆顺序」只读行。
- 保留：基本信息（名称、状态、创建日期、备注）+ 业务范围字段 + 查重范围（所属分馆 / 所属馆藏地；空展示「不限」）。
- 页签结构可保留「基本信息 / 业务范围 / 查重范围」，或等价单页分区；与编辑字段对齐。

---

## 6. 下游查重（文案与数据）

- 馆藏查重仍按当前馆员**关联订户**合并：分馆按订户顺序拼接去重，馆藏地并集；皆空则不限（规则同现 5.9 / 5.3.5.5）。
- PRD 与界面文案：将「配置 → 查重范围」改为「订户编辑中的查重范围」（或「订户列表 · 编辑 · 查重范围」）。
- 查重弹窗仍不展示范围选择；订单查重仍不使用查重范围。

---

## 7. 组件与数据流

| 位置 | 变更 |
|------|------|
| `SubscriberListView` | 去掉配置入口与 permission 状态 |
| `SubscriberFormModal` | 恢复/合并完整字段；灰线查重区；无排序 UI |
| `SubscriberPermissionModal` | 删除或停止引用 |
| `SubscriberDetailModal` | 去数据归属、去分馆顺序展示 |
| `subscriber-manage.js` / PRD 面板数据 | 同步说明；字段模型可不变 |
| PRD `5.9`、`5.3.5.5` 相关表述 | 去配置拆分；改入口文案 |

**数据流**：编辑保存业务 + 查重字段 → 馆员查重时合并关联订户查重范围 → 馆藏检索带范围。

---

## 8. 验收要点

1. 列表无「配置」；新增与编辑同一完整表单。
2. 表单字段顺序与必填符合 §4.1；查重区上下有灰线分隔。
3. 无所属分馆排序控件；无数据归属入口（含详情）。
4. 查重范围可空保存；分馆变更后非法馆藏地被剔除。
5. 详情可读业务与查重范围，无顺序行、无数据归属。
6. 查重相关文案不再指向「配置」。

---

- **5.3.5.5**：馆藏查重范围来源改为订户编辑中的查重范围合并结果。
