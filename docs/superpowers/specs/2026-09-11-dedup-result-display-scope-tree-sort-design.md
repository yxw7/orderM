# 查重结果面板 · 单件显示范围与馆藏树排序

**日期**：2026-09-11  
**状态**：已确认  
**模块**：订单行馆藏查重结果面板「单件」页签（5.3.5.6）；订户单件显示范围合集（5.9）；馆藏查重本馆/全市传参（5.3.5.5）  
**关联**：`2026-09-08-subscriber-embedded-permission-org-design.md`（订户三页签；查重范围 / 单件显示范围字段）

---

## 1. 背景与目标

查重结果「单件」页签当前：全市单件展示；馆藏树一～三级按组织优先合集排序。产品要求：

1. **单件显示范围**从当前馆员关联订户合并去重，同时控制右侧单件列表与左侧馆藏树展示。
2. **所属机构**只影响一级馆藏树与单件列表的优先序；二、三级不做机构类优先排序，同级默认按 `code` 字母+数字升序。
3. 馆藏树**仅排序后的第一个一级节点默认展开**，其余一级默认收起。
4. 澄清本馆/全市统计传参：默认用所属机构下所属馆合集；查重范围非空时改用查重范围。

### 1.1 目标

1. 新增「单件显示范围」合集解析与单件过滤、馆藏树裁剪。
2. 简化馆藏树 / 单件排序规则，并固定一级默认展开策略。
3. 对齐馆藏查重本馆/全市请求参数口径。
4. 同步 `docs/prd.md` 与相关 PRD 抽屉（实现阶段）。

### 1.2 非目标

- 不改订单查重。
- 不改查重配置弹窗 UI（范围仍不在弹窗内选）。
- 不新增用户可配的树排序 / 展开 UI。
- 不改书目 / MARC / 订单页签交互（除本馆全市字段若随传参语义调整展示文案外）。

## 2. 方案选型

**已选：方案 1 — 先筛单件 → 再按残留单件裁剪馆藏树 → 再排序**

| 方案 | 说明 | 结论 |
|------|------|------|
| 1 | 筛单件后裁剪树，保证树与列表一致 | **采用** |
| 2 | 树与单件各自按合集独立过滤 | 易出现空叶子，不采用 |
| 3 | 用筛后单件自底向上重建树 | mock 名映射易残缺，不采用 |

---

## 3. 数据源与职责划分

### 3.1 合集来源（均按馆员关联订户顺序合并，去重保序）

| 合集 | 来源字段 | 用途 |
|------|----------|------|
| 单件显示范围 · 分馆 | `displayBranchCodes` | 结果面板单件 / 树展示过滤 |
| 单件显示范围 · 馆藏地 | `displayCollectionCodes` | 同上（优先于分馆，见 §4） |
| 查重范围 · 分馆 / 馆藏地 | `dedupBranchCodes` / `dedupCollectionCodes` | 馆藏检索范围；本馆/全市传参（非空时） |
| 所属机构 | `institutionId`（所属组织） | 一级树 / 单件优先序；本馆/全市默认传参的机构锚点 |

### 3.2 本馆 / 全市统计传参（馆藏查重）

1. **查重范围为空**（分馆 + 馆藏地都合集空）  
   → 传参：关联订户「所属组织 → 所属机构」下展开得到的**所属馆合集**（去重保序）。
2. **查重范围非空**  
   → 传参：查重范围的所属分馆 / 所属馆藏地合集（馆藏地合集非空时以馆藏地为准；仅分馆则传分馆）。
3. 接口返回本馆 / 全市单件统计数量；列表与结果摘要展示该返回值。  
   原型可用合集在本地模拟计数，语义与上面对齐。

**单件显示范围不参与**本馆/全市传参，只影响结果面板展示。

---

## 4. 单件过滤

合并后的单件显示范围：

| 合集状态 | 规则 |
|----------|------|
| 分馆、馆藏地皆空 | **不限**，展示全部单件 |
| 馆藏地合集非空 | 只保留所属馆藏地命中合集的单件；**未关联（所属馆藏地为空）不展示** |
| 仅分馆合集非空 | 所属馆解析到的分馆编码 ∈ 合集才展示；未关联单件同样按所属馆分馆是否命中决定 |

匹配：馆藏地用编码（及可解析名称）对齐；分馆用所属馆 → 分馆编码对齐。

---

## 5. 馆藏树裁剪与未关联根

1. 仍先构建含未关联挂载的展示树，再按**筛后单件**剪枝：无残留单件的叶子/中间节点去掉；父无子则去掉。
2. **一级「未关联馆藏地」**：仅当单件显示范围**两维都合集为空**时才允许构建/展示；范围非空时一律不挂该一级根。
3. 分馆下四级「未关联馆藏地」：仅在「仅分馆合集非空」且筛后仍有「有馆无地」单件时，按现有挂载规则保留。

叶子点击筛选仍只在筛后单件集合内进行。

---

## 6. 排序与默认展开

### 6.1 馆藏树

- **仅一级**按所属机构优先合集排序（命中靠前，未命中靠后；同序稳定）。
- **二、三、四级不做**机构 / 馆区 / 分馆优先排序。
- 同级默认按节点 `code` **字母+数字升序**（自然序）；无 `code` 时回退可解析编码，再不行用名称。
- 一级「未关联馆藏地」（仅显示范围全空时可能出现）固定排在一级**末尾**。

### 6.2 单件列表

- 优先序只按所属馆对应**所属机构**在机构合集中的先后。
- 同机构内再按所属馆 `code`（其次馆藏地 `code`）升序。
- 取消「分馆 → 馆区 → 机构」三级复合优先。

### 6.3 默认展开

- 排序完成后，**仅第一个一级节点默认展开**；其余一级默认收起。
- 用户可手动展开/收起；切换书目时按上述规则重新套用默认展开。

## 7. 实现触点（供计划，非业务正文）

- 订户侧：合并单件显示范围合集（与现有查重范围合并并列）。
- 查重结果抽屉：过滤 → 裁剪 → 排序 → 默认展开。
- 馆藏查重提交：本馆/全市传参按 §3.2。
- PRD：`docs/prd.md` 5.3.5.5 / 5.3.5.6 / 5.9 交叉表述；订单/订户抽屉数据。

## 8. 验收要点

1. 显示范围全空：单件与树不限；可出现一级未关联根（有数据时）；仅首个一级默认展开。
2. 仅有馆藏地合集：未关联不出现；树/表仅命中馆藏地。
3. 仅有分馆合集：按所属馆分馆过滤；无一级未关联根。
4. 一级顺序跟机构合集；二三级仅 code 升序，无机构优先。
5. 查重范围空/非空时，本馆全市传参分别走机构下所属馆合集 / 查重范围。
