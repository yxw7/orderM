# 查重结果面板合并（馆藏 + 订单）

## 背景

当前订单行列表「馆藏重复」「订单重复」分别打开两套顶部下拉面板（`DedupResultDrawer` 按 `duplicateType` 分支）。需合并为同一面板：在原馆藏查重结果的「单件」页签后增加「订单」页签；同时调整书目/单件页签：馆藏树从书目行展开迁至单件页签左右分栏。

## 目标

- 一套查重结果面板同时展示馆藏结果与订单结果。
- 页签顺序：书目 → MARC信息 → 单件 → **订单**。
- 按列表入口决定默认页签；面板标题与摘要统一。
- **单件页签**：左侧馆藏树 + 右侧单件列表；书目页签不再展开馆藏树。

## 行为

### 入口与默认页签

| 入口 | 条件 | 打开后默认页签 |
|------|------|----------------|
| 馆藏重复「有」 | `holdingDuplicate === true` | 书目 |
| 订单重复「有」 | `orderDuplicate === true` | 订单 |

- 「无」或空白仍不响应点击。
- 打开后面板内可自由切换四个页签，不因入口限制可见性。

### 面板结构

自上而下：**标题栏** → **摘要信息区** → **页签栏** → **结果内容区** → **分页栏**（按页签规则显隐）。

| 区域 | 规则 |
|------|------|
| 标题 | 统一为「**查重结果**」（不再区分「馆藏查重结果 / 订单查重结果」） |
| 摘要 | 一行：订单行号、查重字段、**重复记录数：馆藏 M · 订单 N**（M = `holdingDedupResults.length`，N = `orderDedupResults.length`） |
| 页签 | 始终展示：书目、MARC信息、单件、**订单**（文案固定为「订单」，**不**带数量后缀） |
| 书目 | 见下方「书目页签」；**不再**行内展开馆藏树 |
| MARC信息 | 左右分栏（订单行信息 \| MARC）；左侧为字段名/字段内容表格，便于与右侧对照 |
| 单件 | 见下方「单件页签（左右分栏）」 |
| 订单 | 列表上方发/收/换/退/撤订数量汇总；表格与分页沿用原订单查重结果 |
| 分页栏 | 书目、订单页签显示；MARC、单件页签不占位 |
| 面板高度 | 书目 / 订单约 75vh；MARC / 单件约 88vh（与现馆藏规则一致） |
| 空态 | 当前页签对应数据为空时，内容区显示「暂无查重结果」（单件页签细则见下） |

### 书目页签

- 表格展示重复书目；列顺序：**单选** → **单件数量** → 书目字段 → **操作**（**去掉**行首展开/收起列及行下馆藏树）。
- **单选列**：每行一个 radio；同一时刻仅一条书目被选中。
  - 打开面板 / 馆藏结果分页切换后：默认选中**当前页第一条**书目（若无结果则无选中）。
  - 选中某条书目后，再切换到「MARC信息」「单件」页签时，展示的均为**当前单选书目**的 MARC / 馆藏树与单件。
  - 在书目页签内改选另一条：若随后切到 MARC / 单件，内容随新选中书目切换；单件页签的四级叶子选中状态重置。
- 操作列仍含「关联/取消关联」（已去掉「查看」「单件」；通过单选 + 切换页签查看 MARC / 单件）。
- 「单件数量」列规则不变（蓝/灰徽章「N本」）。
- 无单件（0本）的书目仍出现在列表，可单选、查看 MARC、关联。

### 单件页签（左右分栏）

布局：左侧馆藏树**固定约 20%**（不可拖拽）、右侧单件列表约 80%；左侧树在宽度不足时可出现**横向滚动条**，过高时左右可独立纵向滚动；**不显示底部分页栏**。

| 侧 | 内容 |
|----|------|
| **左侧** | 当前选中书目的馆藏树：机构 → 馆区 → 分馆 → 馆藏地；有未分配馆藏地单件时追加叶子「**未关联馆藏**」（与馆藏地同级，按四级叶子处理） |
| **右侧** | 单件列表明细：馆藏状态（首列）、条码号、索书号、所属馆、所属馆藏地、所在馆、所在馆藏地、借阅类型、卷册描述、装帧（精装/平装）、排架标引分类、排架标引、登到时间 |

#### 树节点交互

| 节点层级 | 点击行为 |
|----------|----------|
| 一 / 二 / 三级（机构、馆区、分馆） | **仅**展开 / 收起子节点，不改变右侧列表 |
| 四级馆藏地叶子 | 选中该节点；右侧仅显示**所属馆藏地**对应该节点的单件 |
| 「未关联馆藏」叶子 | 同四级：选中后右侧仅显示未分配馆藏地的单件 |

- 选中四级叶子时左侧高亮当前节点；再次点击同一叶子可保持选中（不必取消）；切换其它叶子则换过滤。
- 提供「清除馆藏地筛选」不是本版必需：进入页签或切换书目时默认无叶子选中即可回到「全部单件」。

#### 右侧列表与空态

| 场景 | 右侧展示 |
|------|----------|
| 进入单件页签 / 直接点「单件」页签且**未选**四级叶子 | 当前单选书目的**全部**单件 |
| 已选四级馆藏地或「未关联馆藏」 | 过滤后的单件子集 |
| 该书目单件数量 = 0 | 左侧可无树或提示暂无馆藏分布；右侧「暂无单件信息」 |
| 已选叶子但该节点下无单件 | 「暂无单件信息」 |

#### 与书目的绑定

- MARC / 单件页签始终绑定书目页签**当前单选**的书目（`activeHoldingBib`）。
- 直接点「MARC信息」或「单件」页签：使用当前单选书目；若尚未选中则回落到结果列表第一条并同步单选。
- 在书目页签改选 radio 后：切到 MARC / 单件即展示该书目；切换书目时单件页签四级叶子选中重置，右侧回到该书目全部单件。

### 数据

- 抽屉同时使用本行 `holdingDedupResults` 与 `orderDedupResults`。
- `duplicateType`（或等价入口标记）**仅用于决定打开时的默认页签**，不再切换整套 UI 模式。
- 列表标识列逻辑不变：仍分别由 `holdingDuplicate` / `orderDuplicate` 控制「有/无」。
- 四级过滤依据：单件「所属馆藏地」与树叶子节点对应关系（含 `unassigned` 标记对应未关联单件）。

## 实现要点

| 项 | 说明 |
|----|------|
| `DedupResultDrawer.vue` | 合并分支；页签含 `order`；书目单选列驱动 MARC/单件；书目去展开列；单件左右分栏 + 树选中过滤；摘要双计数 |
| `HoldingTree` / 节点 | 支持叶子选中回调；一至三级仅 toggle；四级/`unassigned` 触发筛选 |
| `OrderManageView` | 向抽屉同时传入馆藏与订单结果（或抽屉内直接读 line） |
| store | `openDedupDrawer(line, entryType)` 保留；`entryType` 映射默认页签 |
| PRD 5.3.5.6 | 合并面板；书目单选绑定 MARC/单件；书目不再展开树；单件左右分栏与四级筛选 |

## 非目标

- 不改变查重配置、比对算法、自动关联书目规则。
- 不合并列表上的「馆藏重复」「订单重复」两列标识。
- 不在本变更中改订单结果表列或增加订单行跳转操作。
- 订单页签标题不展示数量（N）；数量仅出现在摘要与分页区。
- 不在本版增加「点击已选四级叶子取消筛选」的强制交互（靠切换书目/重新进入即可回全部）。

## 验收

1. 点馆藏重复「有」→ 面板标题为「查重结果」，默认「书目」，可见「订单」页签（无数量后缀）；书目行**无**展开馆藏树；**默认单选第一条**书目。
2. 单选另一条书目后，切换到 MARC / 单件，内容为该选中书目。
3. 点订单重复「有」→ 同一面板，默认「订单」，可切回书目/MARC/单件。
4. 进入单件页签：左侧馆藏树、右侧先显示当前选中书目全部单件；点一～三级仅展开收缩；点四级馆藏地或「未关联馆藏」后右侧过滤为对应单件。
5. 订单结果条数体现在摘要「馆藏 M · 订单 N」及订单页签底部分页；页签文案始终为「订单」。
6. MARC/单件无面板底部分页；书目操作列仅保留关联/取消关联。
