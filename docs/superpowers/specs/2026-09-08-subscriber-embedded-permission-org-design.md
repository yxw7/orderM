## 1. 背景与目标

订户新增/编辑当前为：业务字段（含必填「单件所属馆」）+ 灰线分隔的查重范围（所属分馆/馆藏地多选，含提示文案「查重范围 · 未选分馆/馆藏地视为不限」）。

产品要求：

1. 去掉查重提示文案与所属馆藏地。
2. 原「单件所属馆」与查重「所属分馆」合并为「所属分馆」（单选），并上移到机构组织层级中。
3. 增加所属机构（必填）、所属馆区（非必填）；层级为机构 → 馆区 → 分馆。
4. 表单整体改为：上半基本信息（名称、备注）+ 下半固定四许可侧栏布局（参考权限配置截图，但**无**「添加操作许可」）。
5. 列表列「单件所属馆」改为「所属机构」；详情页签改为「基本信息 / 权限范围」。

### 1.1 目标

1. **新增 / 编辑**同一宽弹窗：名称 + 备注 + 内嵌四许可配置，一次提交。
2. 左栏固定四项：**资源类型范围**、**预算管理范围**、**条码号类型范围**、**所属组织机构**；点选切换右侧。
3. 所属组织机构：机构* / 馆区 / 分馆，均为单选；上级变更清空下级。
4. 操作列**不增加**「权限配置」。
5. 馆藏查重范围按机构组织收窄（机构必参与）；结果 UI 后续再改。
6. 同步 `docs/prd.md`、订户前端原型与 PRD 抽屉数据。

### 1.2 非目标

- 独立权限配置入口 / 「添加操作许可」动态清单
- 查重结果树、单件列表、查重配置弹窗的交互改造
- 数据归属、分馆排序 UI
- 机构/馆区主数据管理后台（本版可用 mock / 扩展现有 location 数据）

**已选：权限配置嵌套进新增/编辑（方案 C）**

| 入口 | 内容 |
|------|------|

| 列表「权限配置」 | **不提供** |
| 查看详情 | 基本信息 / 权限范围 |

未选：双弹窗拆分（独立权限按钮）；新增两步向导。

## 3. 列表

- 表格列：原「单件所属馆」→ **「所属机构」**（取订户所属机构展示名 `institutionName`；空则「—」）。
- 筛选：原按单件所属馆的条件对齐改为按所属机构。
- 资源类型、预算名称等列仍展示权限范围内已选值。
- 操作列：编辑、停用/启用、删除（与现逻辑一致）；**无**权限配置按钮。
- 点订户名称仍打开查看详情。

## 4. 新增 / 编辑弹窗

- 组件：改造 `SubscriberFormModal`（或等价）；标题「新增订户」/「编辑订户」。
- 宽度建议加宽（约 `max-w-3xl`～`max-w-4xl`），以容纳左右栏；内容区可纵向滚动；底栏取消 / 提交（新增）或取消 / 保存（编辑）。
- **一次提交**：基本信息与四许可一并校验、一并保存；校验失败不关窗，可自动切到首个失败的许可页。

### 4.1 上半 · 基本信息

| 顺序 | 字段 | 英文字段名 | 必填 | 控件 |
|------|------|------------|------|------|
| 1 | 订户名称 | name | 是 | 文本；去首尾空格；最长 50；不可与其他订户重名 |
| 2 | 备注 | remark | 否 | 多行文本；最长 500 |

### 4.2 下半 · 固定四许可（左栏）

左栏为**固定列表**（非用户增删），顺序：

1. 资源类型范围  
2. 预算管理范围  
3. 条码号类型范围  
4. 所属组织机构  

默认选中第一项「资源类型范围」。无「添加操作许可」、无已选许可删除图标。

### 4.3 右侧 · 各许可字段

| 许可 | 字段 | 英文字段名 | 必填 | 控件 / 规则 |
|------|------|------------|------|-------------|
| 资源类型范围 | 资源类型 | types | 是（≥1） | 可搜索多选；选项同现网 |
| 预算管理范围 | 预算名称 | budgets | 是（≥1） | 可搜索多选；选项同现网 |
| 条码号类型范围 | 条码号类型 | barcodeTypes | 是（≥1） | 可搜索多选；选项同现网 |
| 所属组织机构 | 所属机构 | institutionId | 是 | 可搜索单选 |
| 所属组织机构 | 所属馆区 | campusId | 否 | 可搜索单选；选项依赖已选机构 |
| 所属组织机构 | 所属分馆 | branchId | 否 | 可搜索单选；选项依赖已选馆区。**本版约定**：未选馆区时分馆下拉禁用，仅允许分馆为空或先选馆区后再选分馆 |

**层级交互**：

- 变更所属机构 → 清空馆区、分馆。  
- 变更所属馆区 → 清空分馆。  
- 停用节点：编辑时已选项仍可展示（与现分馆停用保留展示一致）。

**废弃 UI / 字段**：

- 标签「单件所属馆」  
- 提示「查重范围 · 未选分馆/馆藏地视为不限」  
- 所属馆藏地（`dedupCollectionCodes`）  
- 查重用多选所属分馆（`dedupBranchCodes`）  
- 灰线「查重范围」独立业务区块（改由四许可中的所属组织机构承担）

### 4.4 校验提示

| 场景 | 提示 |
|------|------|
| 名称为空 | 请输入 |
| 名称超长 | 已超字符限制 |
| 名称重复 | 已存在 |
| 备注超长 | 已超字符限制 |
| 资源类型/预算/条码未选 | 请选择 |
| 所属机构未选 | 请选择 |

## 5. 查看订户详情

- 页签：**基本信息** / **权限范围**（废弃「业务范围」「查重范围」页签）。

- 权限范围（只读）：
  - 资源类型、预算名称、条码号类型（多值展示）
  - 所属机构、所属馆区、所属分馆（空则「—」）
- 底部：关闭；不修改数据。

## 6. 馆藏查重范围语义（订户侧）

本版只定义订户配置与合并提交字段；**不改**查重结果面板。

1. **机构参与收窄**：仅选机构、馆区/分馆皆空 → 限定该机构下全部馆藏范围。  
2. 再选馆区 → 收窄到该馆区；再选分馆 → 收窄到该分馆。  
3. **馆员多订户合并**：按馆员关联订户先后顺序，合并各订户的机构组织范围（编码首次出现保留；机构/馆区/分馆分别合并，具体编码键与后端对齐时落 PRD 接口表）。  
4. 订单查重仍**不使用**本范围，仅按关联订户比对订单行。

废弃：以 `dedupBranchCodes` + `dedupCollectionCodes` 作为查重范围来源。
