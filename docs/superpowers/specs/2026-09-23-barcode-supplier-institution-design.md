# 条码号供应商代码 · 所属机构

**日期**：2026-09-23  
**状态**：已评审（2026-09-23）  
**范围**：设置 → 条码号供应商代码（`/barcode-supplier`）  
**关联**：
- 机构数据隔离（`2026-09-21-institution-data-isolation-design.md` §8.6.7）
- 条码校验规则（`2026-09-15-barcode-validation-rule-config-design.md`）馆配商代码段取值来源

---

## 1. 背景与目标

### 1.1 背景

「条码号供应商代码」现无所属机构字段；列表按代码拆成多行；唯一性按「同条码号类型下代码不重复」。多机构租户下需按机构归属维护配置，并与机构隔离规格对齐。

### 1.2 目标

1. 配置归属到机构；列表与写入按当前用户机构范围过滤。
2. 配置粒度：一行 = **机构 + 条码号类型 + 供应商**；一行可含多个条码号代码（`;` 分隔），列表不按代码拆行。
3. 新增/编辑弹窗首位展示所属机构；编辑时机构、类型、供应商只读。
4. 与条码校验规则「馆配商代码」段约定：按**同一机构**解析本模块配置。

### 1.3 非目标

- 不改业务中台账号/分馆同步接口。
- 不迁移历史业务单据。
- 不在本期改验收自动分配条码逻辑。
- 检索区不加所属机构筛选项。

---

## 2. 方案

**采用**：对齐机构隔离 + 条码校验规则模式。

- 行级存 `institutionId`；列表派生展示所属机构名称。
- 机构范围复用隔离规格：`resolveInstitutionScopeIds()`（S2/S3 = 关联订户机构合集；S1 = 所在馆倒推机构；S0 = 空）。
- 存储一行多码，取消按代码拆行。

---

## 3. 数据模型

| 字段 | 说明 |
|------|------|
| `institutionId` | 必填；所属机构 |
| `barcodeType` | 条码号类型 |
| `supplierCode` / `supplierName` | 供应商代码 / 名称 |
| `barcodeCode` | 单行内多码，英文分号 `;` 分隔（如 `01;02`） |
| `status` / `remark` / `creator` / `created` | 同现网 |

**唯一键（配置）**：`(institutionId, barcodeType, supplierCode)`（表单选供应商名称后写入对应 `supplierCode`）。

**代码唯一（跨供应商）**：同一 `institutionId` + `barcodeType` 下，任一 `barcodeCode` 片段不得被其它配置行占用。

**Mock 迁移**：原同类型 + 同供应商的多行合并为一行（代码 `;` 拼接），并补 `institutionId`。

---

## 4. 权限与列表

### 4.1 机构范围

| 状态 | 读 | 写 | 范围 |
|------|----|----|------|
| S0 | 空列表 | 否 | 无 |
| S1 | 是 | 是（按角色） | 所在馆 → 倒推机构；写入固定该机构 |
| S2/S3 | 是 | 是（按角色） | 关联订户所属机构合集；写入须 ∈ 合集 |

解析：有关联订户 → 订户机构合集；否则有所在馆 → 倒推机构；皆无 → 空。

### 4.2 列表与检索

- 列：序号后增加「所属机构」；「条码号代码」直接显示多码文本；其余列保留。
- 检索：不加所属机构条件；先按机构范围过滤，再套检索。
- 启停/删除：作用于整行（整组配置）。

---

## 5. 新增 / 编辑

### 5.1 字段顺序

1. 所属机构（必填下拉，选项 = 当前用户机构范围；范围仅 1 个时可默认选中）
2. 条码号类型
3. 供应商名称
4. 条码号代码（多码 `;` 分隔，每位 2 位数字）
5. 状态
6. 备注

### 5.2 编辑只读

所属机构、条码号类型、供应商名称只读；可改代码、状态、备注。回显该行全部代码（`;` 拼接），保存整行覆盖。

### 5.3 校验

1. 机构 + 类型 + 供应商已存在 → 拦截（编辑排除自身）。
2. 同机构 + 同类型下，提交的每个代码不得与其它行冲突。
3. 同条内代码不重复；格式非法提示沿用现网风格。
4. 写入 `institutionId` 必须在当前用户机构范围内。

一次提交写/更新**一行**，不再按代码拆行。

---

## 6. 与条码校验规则联动

规则含「馆配商代码」段时，按同一 `institutionId` + 条码号类型 + 供应商解析本模块配置；跨机构不复用。本期可不接业务生成，保证配置数据与约定一致即可。

## 8. 验收

1. 列表有所属机构列；无机构范围时为空；有订户用合集，无订户有所在馆则倒推机构。
2. 新增弹窗首位为所属机构；编辑时机构 / 类型 / 供应商只读。
3. 同机构 + 类型 + 供应商不可重复配置。
4. 同机构 + 类型下代码不跨供应商重复；一行可含多码且列表不拆行。
5. 启停 / 删除作用于整行配置。
