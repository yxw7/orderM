## 1. 背景与目标

用户需在订单行列表通过导入 Excel 批量更换供应商（及预算）：弹窗填写新订单抬头，模板只填原订单行号、套数、备注；全部校验通过后生成一条待发订新订单，并按行迁出套数回写原行。

### 1.1 目标

- 工具栏「更换供应商」打开三步导入向导
- 固定列模板，可下载
- 全有或全无；Excel 内须同一原订单号
- 生成 1 条新订单 + N 条新订单行；原行按套数撤订

### 1.2 非目标

- 列映射 / 任意表头
- 一份 Excel 跨多个原订单生成多张新单
- 改造行内「更换供应商」
- 改造催缺侧更换供应商
- 真实后端；前端 mock

---

## 2. 方案

**固定模板 + 弹窗先填抬头 + 三步向导（已选）**

1. 填写订单名称、供应商、预算  
2. 下载模板并上传 Excel  
3. 校验预览 → 全通过后确认生成  

---

## 3. 入口

| 项 | 约定 |
|----|------|
| 位置 | 订单行列表工具栏 |
| 文案 | **更换供应商** |
| 行内 | 仍为单行弹窗（见行内规格）；与工具栏并存 |

工具栏入口**不依赖**勾选行；以 Excel 中的订单行号为准。

---

## 4. 三步向导

### 4.1 步骤① 填写抬头

| 字段 | 必填 | 说明 |
|------|------|------|
| 订单名称 | 是 | 写入新订单；长度遵循订单名称上限 |
| 供应商 | 是 | 必选；是否属于原订单采选方式选项在步骤③确认（见下） |
| 预算名称 | 条件必填 | 与新建订单一致：交换/捐赠可空，其余必填；method 以原订单为准，在步骤③判定 |

本步可提供「下载模板」（未上传文件亦可先下载空白模板）。

**采选方式与预算校验时机**：模板不含原订单信息。步骤①只校验订单名称、供应商非空，预算可先填写（允许空）。步骤③解析出唯一原订单后：

1. 用该订单 method 判定预算是否必填；必填且为空 → 整批失败  
2. 校验步骤①供应商是否属于该 method 的可选供应商；不通过 → 整批失败

### 4.2 步骤② 上传文件

- 仅 `.xls` / `.xlsx`
- 解析后进入步骤③

### 4.3 步骤③ 校验确认

- 展示通过行数 / 失败行数及原因摘要  
- 失败时可「下载校验结果」  
- **全部行通过**才启用「生成新订单」  
- 任一行失败：不可提交；不改 store  

---

## 5. Excel 模板列

| 列名 | 必填 | 说明 |
|------|------|------|
| 订单行号 | 是 | 定位原订单行 |
| 套数 | 是 | 迁出套数 |
| 备注 | 否 | 写入对应**新订单行**备注 |

---

## 6. 行校验规则

对 Excel 每一数据行：

1. 订单行号在系统中存在  
2. 行状态 ∈ {已发订, 处理中}  
3. 验收状态 ∈ {待验收, 部分收货, 换货中}  
4. 可迁出套数 ≥ 1；可迁出 = `max(0, 发订 − 已收 − 已退 − 已换)`  
5. 套数为整数且 `1 ≤ 套数 ≤ 可迁出`  
6. 文件内所有行的原订单号（orderId）**相同**  
7. 同一订单行号在文件中不重复  
8. 步骤①供应商适用于该原订单采选方式；预算按该 method 必填规则通过  

任一条不满足 → 该行失败；存在失败行 → 整批不可生成。

---

## 7. 提交数据流

全通过后：

1. **新建 1 条订单头**  
   - 名称/供应商/预算 = 步骤①  
   - 订户、馆址、资源类型、语种、采选方式、折扣 = 原订单继承  
   - 状态：待发订  

2. **按 Excel 每行新建订单行**（顺序与文件一致）  
   - 套数与发订段 = 填写套数；`flowStats` = `{套数}/0/0/0/0`  
   - 书目字段自原行复制；备注 = Excel 备注  
   - 行状态待发订；是否催缺 = 否  

3. **回写各原行**  
   - 撤订段 += 本次套数；原因固定「更换供应商」  
   - 按现有部分撤订补丁重算行状态/验收状态  

4. **收尾**  
   - 成功确认：「已生成新订单 {orderId}，…是否立即查看？」→ 确定跳转订单列表  
   - 提交前再跑一遍校验（防并发）；失败则整批中止  

因限制同一原订单且抬头供应商/预算全局唯一，合并键「原订单号 + 新供应商 + 新预算」在本流程中自然得到**恰好 1 条**新订单。

## 9. 提示与导出（示意）

| 场景 | 处理 |
|------|------|
| 抬头缺必填 | 阻断进入上传或提示补全 |
| 文件格式不对 | 请上传 Excel |
| 跨原订单 / 行校验失败 | 步骤③展示失败；下载校验结果；不可生成 |
| 成功 | 确认框含新订单号；可跳转订单列表 |

---

## 10. 测试要点

1. 工具栏打开向导；行内入口不受影响  
2. 模板仅三列；下载可用  
3. 两行不同原订单号 → 整批失败  
4. 套数越界、状态不符、行号不存在、重复行号 → 失败可下载  
5. 全通过 → 1 新单 + N 新行；原行撤订数量正确  
6. 交换/捐赠原单：预算可空；其他 method 预算必填  
7. 有失败行时点击生成无效
