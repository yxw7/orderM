# 馆址管理：从四级馆藏地勾选加入

**日期**：2026-09-16  
**状态**：已确认  
**模块**：设置 · 馆址管理（`/locations`）  
**关联**：
- 现有馆址管理三页签：馆址 / 分馆 / 馆藏地（`html/src/modules/location/`）
- 四级馆藏地接口（馆址 → 分馆 → 馆藏地）
- 当前馆员关联订户「所属组织 → 所属机构」及机构 → 馆区 → 馆址映射（`org-hierarchy`）

---

## 1. 背景与目标

馆址管理当前「新增」为手填编码/名称，并用硬编码四级编码白名单校验；另有「批量导入」。实际业务需要：**从四级馆藏地接口勾选已有节点加入列表**，且勾选节点的**业务身份以当前页签为准**（接口中的馆藏地也可加入为本地馆址），因此本地层级可与接口树不一致。

同时，馆址管理需按**当前登录馆员关联订户的所属机构**做数据权限过滤；馆址列表需展示机构编码/名称便于对照。

### 1.1 目标

1. 隐藏原「新增」「批量导入」入口，改为统一「从四级馆藏地加入」。
2. 弹窗内从四级树多选节点，按当前页签写入馆址 / 分馆 / 馆藏地列表（身份可换）。
3. 分馆 / 馆藏地加入前必须先选本地已有上级；树勾选不自动级联下级。
4. 同批与已有编码冲突时跳过并提示。
5. 列表与树均受关联订户所属机构权限约束；馆址列表增加机构编码、机构名称列。

### 1.2 非目标

- 不保留手填新增与批量导入（本期移除入口；旧弹窗逻辑可保留供编辑复用或删除死代码，以实现时清理为准）。
- 不支持勾选父节点自动带入全部下级。
- 不在加入时自动创建缺失的上级节点。
- 不改造订单、查重等下游对馆址主数据的消费方式。
- 分馆 / 馆藏地列表本期不增加机构列。

---

## 2. 方案选型

**已选：上级栏 + 四级树勾选弹窗（方案 A）**

| 方案 | 说明 | 结论 |
|------|------|------|
| A | 弹窗顶部选本地上级（按页签），下方四级树多选 + 搜索 | **采用** |
| B | 两步向导（先上级后树） | 多一步，馆址页冗余，否决 |
| C | 左树右已选双栏 | 过重，否决 |

**已确认的交互约束**：

- 任意页签可勾选树中任意层级节点；提交时按**当前页签类型**落库。
- 上级：先选本地已有馆址（及分馆），再勾树；不沿用接口原路径自动挂上级。
- 多选；同批编码去重；与列表已有编码冲突则跳过并 toast。
- 勾选父节点只选自身，不级联下级。

## 3. 信息架构与页面

### 3.1 入口

- 路由不变：`/locations`（馆址 / 分馆 / 馆藏地三页签）。
- 工具栏：隐藏「新增馆址|分馆|馆藏地」「批量导入」。
- 新增按钮文案：**从四级馆藏地加入**（三页签共用文案，写入目标由当前页签决定）。

### 3.2 馆址列表列调整

在馆址编码前增加：

| 列 | 说明 |
|----|------|
| 机构编码 | 馆址所属机构 code |
| 机构名称 | 馆址所属机构 name |

机构字段写入馆址主数据（`institutionId` / 展示用 code、name，以实现时字段名为准），**编辑不可改机构**。

检索区本期可不新增机构筛选项（权限已限定可见机构）；若实现时一并加「机构」检索为可选增强，非必须。

### 3.3 分馆 / 馆藏地列表

列结构不变。可见行与上级下拉均受「可见馆址」集合约束。

### 3.4 「从四级馆藏地加入」弹窗

#### 布局（方案 A）

| 当前页签 | 顶部上级区 | 主体 |
|----------|------------|------|
| 馆址 | 无 | 搜索 + 四级树多选 |
| 分馆 | 必选本地所属馆址（仅权限内、使用中） | 同上 |
| 馆藏地 | 必选本地所属馆址 + 所属分馆（分馆随馆址过滤） | 同上 |

- 树节点展示：名称、编码、接口原层级标签（馆址 / 分馆 / 馆藏地）。
- 底部摘要：「已选 N 条 → 将写入「{页签}」列表」。
- 操作：取消 / 提交。

#### 校验（提交前）

| 条件 | 处理 |
|------|------|
| 分馆页未选馆址 | 阻止提交，提示选所属馆址 |
| 馆藏地页未选馆址或分馆 | 阻止提交，提示补全上级 |
| 未勾选任何节点 | 阻止提交，提示至少选择一条 |
| 勾选节点均因冲突被跳过 | 不新增行；toast 说明全部跳过 |

## 4. 写入规则

### 4.1 身份映射

勾选节点的接口层级**仅作展示**；落库类型 = 当前页签：

- 馆址页 → 写入 `siteRows`（馆址）
- 分馆页 → 写入 `branchRows`（分馆）
- 馆藏地页 → 写入 `collectionRows`（馆藏地）

编码、名称取自接口节点；状态默认 `active`（使用中）；备注空。

馆址写入时同时写入所属机构（由权限/映射解析；见第 5 节）。若四级节点本身带机构信息则优先用节点机构，且必须落在馆员权限机构合集内，否则跳过该条并计入跳过原因。

### 4.2 上级绑定

- 馆址：无上级。
- 分馆：`siteId` = 弹窗所选本地馆址；本批所有成功写入的分馆共用该上级。
- 馆藏地：`branchId` = 弹窗所选本地分馆（隐含其 `siteId`）；本批共用该上级。

### 4.3 冲突与去重

1. 同一次勾选内按编码去重（保留首次）。
2. 与**当前页签列表**已有编码冲突 → 跳过该条（不覆盖）。
3. 跨页签同码：允许（例如同一编码在接口是馆藏地、本地已作馆址；再在分馆页加入同码分馆）——冲突检测**仅限当前页签列表内编码唯一**。
4. Toast 示例：`成功加入 3 条分馆；跳过 1 条（编码已存在：ST001）`。全部成功则只报成功条数。

### 4.4 勾选语义

勾选父节点 = 只选该节点；不自动勾选或提交其下级。

## 5. 数据权限

### 5.1 范围计算

1. 当前登录馆员 → 关联订户列表。
2. 各订户「所属组织 → 所属机构」→ 机构 ID 合集（去重保序）。
3. 经机构 → 馆区 → 馆址映射，得到**可见馆址 ID 合集**。
4. 可见分馆 = `siteId` 属于可见馆址；可见馆藏地 = 其分馆属于可见分馆。

### 5.2 作用面

| 面 | 规则 |
|----|------|
| 三页签列表 | 仅展示权限内数据 |
| 加入弹窗上级下拉 | 仅权限内使用中馆址 / 对应分馆 |
| 四级勾选树 | 仅展示权限范围内节点（无权限机构分支不出现） |
| 编辑 / 启停 / 删除 | 仅能操作列表可见行 |

### 5.3 空权限与前置条件

无关联订户，或机构合集为空：

- 三页签列表为空（空态文案）。
- 「从四级馆藏地加入」**禁用**，悬停或旁注提示：无关联订户所属机构权限。

有机构权限但本地尚无可见馆址：

- 馆址页：仍可打开弹窗，从四级树加入馆址。
- 分馆 / 馆藏地页：按钮可点，但上级下拉为空；提交前校验拦截并提示先加入馆址（馆藏地页还须先有分馆）。

## 6. 组件与数据流（原型）

### 6.1 主要改动点

| 单元 | 职责 |
|------|------|
| `LocationManageView` | 隐藏旧入口；新按钮打开加入弹窗；列表按权限过滤；馆址列增加机构字段 |
| 新组件 `LocationLevel4PickModal`（名以实现为准） | 上级选择 + 四级树多选 + 提交 |
| `location-manage.js` / store | 权限过滤、冲突写入、机构字段；移除或停用导入写入路径的入口调用 |
| 四级树 mock/适配 | 提供馆址-分馆-馆藏地树；带机构信息以便权限裁剪 |
| `current-librarian` + `org-hierarchy` | 解析关联订户机构合集与馆址映射 |

### 6.2 编辑与其它

- **编辑**：仍用现有手填弹窗（编码只读；可改名称/状态/备注；馆址不可改机构）。
- **启停 / 删除 / 检索 / 分页**：行为保持，数据源为权限过滤后集合。

### 6.3 错误与提示

- 上级未选、未勾选：字段/底部错误提示，不关闭弹窗。
- 部分成功：关闭弹窗并 toast（含成功与跳过）。
- 四级树加载失败：弹窗内错误态 + 可重试（原型可用静态 mock，预留失败态）。

## 7. 测试要点

1. 馆址页：勾选接口「馆藏地」节点 → 写入馆址列表；编码/名称正确；机构列有值。
2. 分馆页：未选馆址无法提交；选馆址后勾选混合层级节点 → 均成为该馆址下分馆。
3. 馆藏地页：须选馆址+分馆；写入挂在所选分馆下。
4. 勾选父节点不带下级；仅提交勾中节点。
5. 同批重复编码去重；与已有编码冲突跳过并 toast。
6. 权限：仅见关联订户所属机构下馆址及下属分馆/馆藏地；树与下拉一致。
7. 空权限：无机构时列表空且入口禁用；有机构无馆址时馆址页可加入，分馆/馆藏地页因无上级无法提交。
8. 原「新增」「批量导入」按钮不可见。
9. 编辑仍可用；馆址编辑不能改机构编码/名称。
