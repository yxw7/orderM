# 馆藏查重复本数为 0 的业务规则与展示设计

**日期**：2026-07-07  
**状态**：已确认  
**关联模块**：订单行列表 · 馆藏查重（5.3.5.6）

---

## 1 背景

馆藏查重比对馆藏书目库。存在一种边界情况：**匹配到书目记录，但当前无任何实体单件（总复本数为 0）**。馆员既需要知道「书目是否已存在」，也需要判断「是否有实体馆藏」。

## 2 业务决策（方案一）

### 2.1 重复判定

| 条件 | 列表「馆藏重复」 | 是否出现在查重结果 |
|------|-----------------|-------------------|
| 匹配到书目，复本数 > 0 | **有** | 是 |
| 匹配到书目，复本数 = 0 | **有** | 是 |
| 未匹配到书目 | 无 | — |

**结论**：只要匹配到馆藏书目记录，即视为馆藏重复（书目层）；复本数不影响「有/无」判定。

判定逻辑保持：`holdingDuplicate = holdingDedupResults.length > 0`。

### 2.2 复本数统计

单条书目的**总复本数** = 已分配馆藏地复本数 + 未关联馆藏地复本数。

- 已分配：`holdingTree` 各馆藏地叶子节点 `copyCount` 之和
- 未关联：`unassignedCopyCount`

## 3 结果面板展示

### 3.1 书目表格

在操作列前增加 **总复本数** 列：

- 展示格式：`N本`（与馆藏地徽章风格一致）
- 复本数 > 0：蓝色圆角徽章
- 复本数 = 0：灰色圆角徽章，显示 **0本**

### 3.2 馆藏树展开区

| 总复本数 | 展开后展示 |
|---------|-----------|
| > 0 | 四层馆藏树（机构 → 馆区 → 分馆 → 馆藏地）+ 未关联馆藏地节点（挂在首都图书馆下，如有） |
| = 0 | **暂无馆藏分布**（不展示馆藏树） |

书目信息、MARC、关联等操作不受复本数影响。

## 4 列表筛选

「馆藏重复 = 有」筛选包含复本数为 0 的书目匹配行，与判定规则一致。

## 5 示例数据

订单行 `PG001B202406030001-3`（信息资源管理）预置一条复本数为 0 的匹配书目，用于演示。
