# 书目查询 — 捐赠来源方与新建订单字段规则 — 设计规格

**日期**：2026-07-06  
**状态**：已评审待实现  
**模块**：书目查询 / 关联订单行页签 / 加入订单弹窗、新建订单弹窗

---

## 1. 背景与目标

### 1.1 业务背景

- 采选方式为「捐赠」时，PRD 规定订单供应商来自**个人管理**（类型=捐赠）与**资源商管理**（类型=团体捐赠）。
- 采编集成规则：采访方式为捐赠时，**捐赠人需同步至单件信息的「来源方」**字段。
- 捐赠人主数据在供应商系统中维护；编目人员在加入订单时需记录捐赠人联系信息，并支持将新捐赠人反向建档到供应商系统。

### 1.2 目标

1. **加入订单弹窗**：当所选订单含捐赠订单时，增加「来源方」区域，支持检索已有捐赠人或手工录入新捐赠人（姓名、电话、省份、详细地址），可选同步新增到供应商系统。
2. **新建订单弹窗**：采选方式为捐赠时，预算名称、供应商、折扣字段**非必填且禁用**，捐赠人信息改在加入订单阶段通过来源方填写。

### 1.3 非目标（本期不做）

- 新建订单弹窗的来源方录入能力（捐赠人仅在加入订单时填写）。
- 已有捐赠人信息修改或反向更新供应商主数据。
- 供应商系统真实 API 联调（mock 模拟检索与建档）。
- 来源方字段在订单列表中的展示列（仅在订单行数据中存档）。
- Z3950、订单行详情等其他入口的来源方能力。

## 2. 需求决策记录

| 项 | 结论 |
|----|------|
| 来源方定位 | 可替代供应商选择；支持检索已有捐赠人或手工录入新捐赠人 |
| 显示条件 | 所选订单中有任意一条为「捐赠」即显示；提交时仅对捐赠订单写入来源方 |
| 多选捐赠单 | 共用一份来源方（与币种/定价共用逻辑一致） |
| 字段规则 | 姓名必填；电话、省份、详细地址选填 |
| 已有捐赠人 | 选中后姓名/电话/省份/详细地址只读，不可修改；界面不展示类型标签 |
| 新增捐赠人类型 | 类型单选：个人捐赠 / 团体捐赠，默认个人捐赠 |
| 反向维护 | 「同步新增到供应商系统」复选框，默认勾选；仅对新捐赠人生效 |
| 反向维护路由 | 个人捐赠 → 个人管理；团体捐赠 → 资源商管理 |
| 采选方式检索 | 加入订单弹窗检索区采选方式为单选 |
| 新建订单捐赠规则 | 预算、供应商、折扣非必填且禁用 |
| 范围 | 加入订单来源方 + 新建订单捐赠字段规则 |

## 3. 方案选型

### 3.1 来源方录入交互

| 方案 | 说明 | 结论 |
|------|------|------|
| **A. 可检索下拉 + 内联表单** | 姓名 combobox；选中已有 → 只读；无匹配 → 可编辑 + 类型单选 + 同步复选框 | **采用** |
| B. 模式切换 | 「选择已有 / 新增捐赠人」单选切换两套表单 | 操作步骤多，不采用 |
| C. 子弹窗检索 | 独立弹窗选择捐赠人 | 交互过重，不采用 |

### 3.2 来源方填写粒度

| 方案 | 说明 | 结论 |
|------|------|------|
| **A. 共用一份** | 多笔捐赠订单共用同一来源方 | **采用** |
| B. 按订单分别填写 | 每条捐赠订单独立来源方 | 不采用 |

## 4. 加入订单弹窗 — 来源方

### 4.1 入口与显示条件

- **入口**：书目查询页 → 选中书目 → 关联订单行页签 → **加入订单**。
- **显示**：`selectedIds` 对应订单中存在 `method === '捐赠'` 时，在馆址分配区下方、币种/定价区上方插入「来源方」区域。
- **隐藏**：取消全部捐赠订单勾选后，隐藏来源方区域并清空表单。

### 4.2 布局

```
┌─ 加入订单 ─────────────────────────────────────┐
│ 【上】检索 + 订单列表                            │
│ ───────── 分隔线 ─────────                       │
│ 【中】馆址分配                                   │
│ ───────── 分隔线 ─────────                       │
│ 【来源方】（仅含捐赠订单时显示）                 │
│   类型    ○ 个人捐赠  ○ 团体捐赠  （仅新增时）  │
│   * 姓名      [ 可检索输入框 ▼ ]                 │
│     电话      [ ____________ ]                   │
│     省份      [ 34省下拉 ▼ ]                     │
│     详细地址  [ ____________ ]                   │
│     ☑ 同步新增到供应商系统  （仅新增时）         │
│ ───────── 分隔线 ─────────                       │
│ 【下】币种 / 定价 / 套内册数 / 备注              │
└────────────────────────────────────────────────┘
```

### 4.3 交互规则

#### 4.3.1 姓名检索（combobox）

- 数据源：「个人管理（类型=捐赠，状态=使用中）」∪「资源商管理（类型=团体捐赠，状态=使用中）」。
- 按姓名模糊匹配；下拉项仅展示姓名（不展示个人/团体标签）。
- 选中列表项 → **已有捐赠人模式**。
- 输入名称无匹配 → **新增捐赠人模式**。

#### 4.3.2 已有捐赠人模式

- 自动填充电话、省份、详细地址。
- 姓名、电话、省份（下拉禁用）、详细地址均为**只读**（`bg-gray-50`，不可编辑）。
- **隐藏**类型单选与「同步新增到供应商系统」复选框。
- `mode = 'existing'`，携带 `donorId` 与 `donorType`（取自记录，界面不展示）。

#### 4.3.3 新增捐赠人模式

- 姓名、电话、省份、详细地址可编辑。
- 省份为 **34 个省级行政区**下拉（见 §4.3.6），默认空（提示「请选择」）。
- 详细地址为单行文本输入，**不超过 100 字符**。
- 显示类型单选：**个人捐赠 / 团体捐赠**，默认「个人捐赠」。
- 显示「同步新增到供应商系统」复选框，**默认勾选**。
- `mode = 'new'`。

#### 4.3.4 提交校验

- 有捐赠订单时，姓名不能为空。
- 电话、省份、详细地址可为空。
- 姓名 ≤ 50 字，电话 ≤ 20 字，详细地址 ≤ 100 字。

#### 4.3.5 提交写入

- 仅对 `method === '捐赠'` 的订单生成订单行并附来源方快照。
- 非捐赠订单正常加入，忽略来源方。
- 多笔捐赠订单共用同一份 `sourceParty`。

#### 4.3.6 省份下拉选项

省份字段使用固定的 **34 个省级行政区**下拉，选项如下（按国家标准顺序）：

北京市、天津市、河北省、山西省、内蒙古自治区、辽宁省、吉林省、黑龙江省、上海市、江苏省、浙江省、安徽省、福建省、江西省、山东省、河南省、湖北省、湖南省、广东省、广西壮族自治区、海南省、重庆市、四川省、贵州省、云南省、西藏自治区、陕西省、甘肃省、青海省、宁夏回族自治区、新疆维吾尔自治区、台湾省、香港特别行政区、澳门特别行政区。

前端抽取为常量 `PROVINCE_OPTIONS`（可置于 `html/src/constants/provinces.js` 或 `donors.js` 同级导出）。

### 4.4 缓存

来源方表单纳入 `bib-order-form-cache` 的 `saveJoinOrderFormCache` / `loadJoinOrderFormCache`，字段：

```javascript
sourceParty: {
  mode: 'existing' | 'new',
  donorType: 'personal' | 'group',
  donorId: string | null,
  name: string,
  phone: string,
  province: string,
  addressDetail: string,
  syncToSupplier: boolean
}
```

## 5. 数据模型

### 5.1 捐赠人主数据（mock）

```typescript
DonorRecord {
  id: string
  name: string
  phone?: string
  province?: string       // 省级行政区
  addressDetail?: string  // 详细地址，≤100字
  type: 'personal' | 'group'   // 个人捐赠 | 团体捐赠
  status: 'active' | 'inactive'
  supplierCode: string
}
```

### 5.2 加入订单提交 payload 扩展

```typescript
JoinOrderPayload {
  siteRows: { orderId: string; site: string; sets: number }[]
  form: { currency: string; price: string; copiesInSet: string; remark: string }
  sourceParty?: {
    mode: 'existing' | 'new'
    donorType: 'personal' | 'group'
    donorId?: string
    name: string
    phone?: string
    province?: string
    addressDetail?: string
    syncToSupplier: boolean
  }

```

### 5.3 订单行扩展字段

订单行仅扩展以下两个字段；电话、省份、详细地址仅在加入订单表单与供应商主数据中维护，**不落库至订单行**。

| 字段 | 说明 |
|------|------|
| `sourcePartyName` | 来源方姓名；收货同步单件时映射至单件「来源方」 |
| `sourcePartyDonorId` | 关联供应商系统捐赠人 ID；新增未同步时为空 |

## 6. 反向维护逻辑

### 6.1 提交流程

```
点击确定
  → 有所选捐赠订单？
    否 → 常规加入订单
    是 → 姓名已填？
      否 → 提示「请填写来源方姓名」
      是 → mode = existing？
        是 → 携 donorId + 快照提交，不写供应商
        否 → syncToSupplier？
          否 → 仅写订单行来源方
          是 → 按 donorType 建档
            personal → 个人管理（类型=捐赠）
            group    → 资源商管理（类型=团体捐赠）
          建档成功 → 获得 donorId，写订单行
          建档失败 → 提示失败，不生成订单行
```

### 6.2 规则表

| 场景 | 行为 |
|------|------|
| 选中已有捐赠人 | 不写供应商；字段只读 |
| 新增 + 复选框勾选 + 个人捐赠 | 个人管理创建记录，状态=使用中 |
| 新增 + 复选框勾选 + 团体捐赠 | 资源商管理创建记录，类型=团体捐赠，状态=使用中 |
| 新增 + 复选框取消 | 仅写订单行，不触碰供应商系统 |
| 新增同步时同名同类型已存在 | 提示「捐赠人已存在，请从列表中选择」，阻止提交 |

## 7. 新建订单弹窗 — 捐赠字段规则

### 7.1 入口

书目查询页 → 书目行 **新建订单** → `BibCreateOrderModal`。

### 7.2 字段联动（`method === '捐赠'`）

| 字段 | 非捐赠 | 捐赠 |
|------|--------|------|
| 预算名称 | 必填，可编辑 | 非必填，**禁用** |
| 供应商 | 必填，可编辑 | 非必填，**禁用** |
| 折扣 | 选填，可编辑 | 选填，**禁用** |
| 必填星号 `*` | 显示 | **隐藏** |

### 7.3 联动规则

1. 切换为「捐赠」→ 清空预算、供应商、折扣，并禁用三字段。
2. 从「捐赠」切回其他采选方式 → 重新启用三字段；预算、供应商恢复必填。
3. 提交校验：`method === '捐赠'` 时跳过预算、供应商、折扣；其余必填项不变。
4. 创建的捐赠订单：`budget`、`supplier`、`discount` 存为空字符串。

### 7.4 与加入订单的配合

捐赠订单创建时不指定供应商；后续通过「加入订单」来源方填写捐赠人，写入订单行并供采编同步。

## 8. 异常处理

| 场景 | 处理 |
|------|------|
| 有捐赠单但未填姓名 | 阻止提交，提示「请填写来源方姓名」 |
| 新增 + 勾选同步，建档失败 | 提示原因，不生成订单行，弹窗保持 |
| 取消全部捐赠单勾选 | 隐藏来源方，清空表单与缓存 |
| 缓存中 donorId 对应记录已停用 | 打开弹窗时清空来源方，提示「原捐赠人已停用，请重新选择」 |
| 新增同步时同名同类型重复 | 提示「捐赠人已存在，请从列表中选择」 |

## 10. 验收要点

### 加入订单

- [ ] 勾选含捐赠订单时显示来源方区域；无捐赠订单时不显示。
- [ ] 检索已有捐赠人：选中后姓名/电话/省份/详细地址只读，无类型标签、无同步复选框。
- [ ] 输入新姓名：显示类型单选（默认个人）与同步复选框（默认勾选），字段可编辑。
- [ ] 姓名必填；电话、省份、详细地址选填；详细地址不超过 100 字符。
- [ ] 多笔捐赠订单共用一份来源方；非捐赠订单不写入来源方。
- [ ] 新增 + 勾选同步：个人 → 个人管理；团体 → 资源商管理。
- [ ] 新增 + 取消同步：仅写订单行。
- [ ] 同名同类型重复时阻止提交并提示。
- [ ] 来源方纳入 join order 表单缓存。

### 新建订单

- [ ] 采选方式=捐赠时，预算、供应商、折扣禁用且非必填。
- [ ] 切换回非捐赠后三字段恢复可编辑；预算、供应商恢复必填。
- [ ] 捐赠订单创建后 budget/supplier/discount 为空。
