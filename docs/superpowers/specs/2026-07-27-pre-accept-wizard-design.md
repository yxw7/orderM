**关联**：

## 1. 背景与目标

在 **不写入收货** 的前提下，勾选验收单后按书商发货单核对系统订单行差异（含已映射字段一致性）。

### 1.1 目标

- 工具栏 **「预验收」**（位于「批验收」之前）
- **三步弹窗**：上传 → 字段映射 → 解析文件（第 ③ 步末尾即结束）
- 匹配池：当前馆员关联订户下、与所选验收单资源类型/语种/采选方式/供应商一致的可收货订单行
- 失败可下载校验结果 Excel（原发货单列 + 校验结果 + 失败原因）

### 1.2 非目标

- 确认收货 / 条码 / 写入验收单
- 数据预览、异步任务

---

## 2. 入口

| 条件 | 结果 |
|------|------|
| 已关联订户 | 可继续校验 |
| 未关联订户 | 「您没有关联订户，无操作权限」 |
| 勾选恰好 1 条未开始/进行中验收单 | 可打开向导；打开前设为当前工作验收单 |
| 未勾选 / 多选 / 已结束 | 按钮禁用或提示「请先在列表中勾选一条未开始或进行中的验收单」 |

---

## 3. 向导步骤

```text
① 上传文件 → ② 字段映射 → ③ 解析文件（完成）
```

### 3.1 上传

仅 `.xls` / `.xlsx`；底部取消 / 上传。

### 3.2 字段映射

- 必填：订单行号、码洋、实洋、收货套数；纸质书为套内册数，视听资料为套内件数（同一映射键）
- 可选：纸质书字段池或视听资料字段池（按验收单资源类型二选一）
- 支持映射模板（与批验收共用）；应用模板时清除当前资源类型不允许的映射值

#### 纸质书（中文+外文合并；验收单资源类型=纸质书时展示）

正题名/题名、ISBN、副题名、分卷号、分卷名、分类号、学科大类、学科细分、中图分类号、中译名、作者/责任者、丛编、出版社、装帧形式、出版年/出版日期、版本/版次、页数、币种、定价/价格、主题词、读者对象、尺寸、语种/正文语种、卷数、出版地、一般性附注、图书简介/简介、精简装ISBN对照、馆藏信息、审读级别、获奖信息、目次信息、作者简介、书评、备注

#### 视听资料（中文+外文合并；验收单资源类型=视听资料时展示）

ISBN、ISRC、题名、载体、出版社/出版方、版本/格式、著者、币种、彩胶颜色、限量编号、厂牌、系列名称、是否签名、是否老唱片、获奖信息、北京出版社、分类、盘号、老唱片品牌、剧种、年代、商品条码、目录号、外文原文题名、备注

### 3.3 解析文件

1. 订单行号匹配关联订户可收货池，且资源类型/语种/采选方式/供应商与验收单一致；否则 **验收单不匹配** 或 **未匹配**  
2. 套数：≤0 或 ＞待收 → **套数非法**；0＜套数＜待收 → **不一致**（收货套数对照）  
3. 其余已映射字段不一致 → **不一致**  
4. 同一行可并存多种失败类型：`校验结果` / `失败原因` 均用 `；` 拼接（如 `套数非法；不一致`）  
5. 命中后不因套数非法中断：仍可比对其他字段  
6. 进度条 → 汇总「共校验到 X 条，其中 X 条成功，X 条失败。」  
7. 下载：Excel，原发货单列 + 校验结果 + 失败原因  
8. 「完成」关闭，不写收货  

| 校验结果 | 条件 | 失败原因示例 |
|--------|------|-------------|
| 通过 | 无失败类型 | — |
| 未匹配 | 无对应可收货订单行 | 无对应可收货订单行 |
| 验收单不匹配 | 资源类型/语种/采选方式/供应商与验收单不一致 | `供应商不一致（验收单 湖北三新/订单行 北京人天）` |
| 不一致 | 已映射字段不等（含部分收货套数） | `"码洋"订单行 58.00/发货单59.00`；… |
| 套数非法 | ≤0 或 ＞待收 | `套数 ≤ 0` / `套数大于待收` |
| 数据错误 | 解析失败等 | 数据解析失败 |

## 4. 与批验收对比

| 维度 | 预验收 | 批验收 |
|------|--------|--------|
