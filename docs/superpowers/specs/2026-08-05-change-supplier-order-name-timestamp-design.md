# 更换供应商 — 订单名称时间戳后缀设计

**日期**：2026-08-05  
**状态**：已评审待实现  
**模块**：非连续出版物订单 / 订单行更换供应商（行内 + 工具栏批量）  
**关联**：
- 行内：`2026-08-03-order-line-partial-change-supplier-design.md`
- 批量：`2026-08-03-order-line-batch-change-supplier-import-design.md`

---

## 1. 背景与目标

同一原订单多次「更换供应商」时，若默认名固定为 `原名-1` 会重复。改为打开弹窗时用时间戳后缀生成默认订单名称；用户可改；**提交时不校验名称是否与已有订单重复**。

### 1.1 目标

- 行内与工具栏批量共用同一命名函数
- 默认名：`{原订单名称}-{yyyyMMddHHmmss}`
- 总长不超过订单名称上限（50）；超长则截断原名部分
- 提交不做订单名称唯一性校验

### 1.2 非目标

- 数字递增后缀（`-1`/`-2`）
- 提交时全局查重拦截
- 改造供应商/预算默认带入逻辑（仍取当前行或勾选首行关联订单）

---

## 2. 方案

**时间戳后缀（已选）**

打开弹窗瞬间取当前本地时间，格式 `yyyyMMddHHmmss`（14 位），拼到原订单名称后。

---

## 3. 命名规则

| 项 | 约定 |
|----|------|
| 原名 | 关联订单的 `orderName`；空则用「新订单」 |
| 后缀 | `-` + `yyyyMMddHHmmss` |
| 长度 | 最终名称 ≤ `ORDER_NAME_MAX_LENGTH`（50）；先预留后缀长度再截断原名 |
| 时机 | 弹窗打开时生成并写入表单；用户可改 |
| 提交 | 仅校验非空与长度等既有规则；**不**校验是否与已有订单重名 |

示例：原名「2026年度地质勘查专题采购」→「2026年度地质勘查专题采购-20260805181122」（若超长则缩短前半段）。

---

## 4. 作用范围

| 入口 | 行为 |
|------|------|
| 行内「更换供应商」 | 打开时 `orderName` = 建议名；供应商/预算仍带入当前行关联订单 |
| 工具栏批量「更换供应商」 | 打开时 `orderName` = 建议名（原名取勾选首行关联订单）；供应商/预算仍带入首行关联订单 |

---

## 5. 实现要点

| 单元 | 变更 |
|------|------|
| `order-line-change-supplier.js` | `suggestChangeSupplierOrderName(sourceOrderName, now = new Date())` 改为时间戳后缀 |
| `OrderLineChangeSupplierModal.vue` | 打开时调用更新后的建议名 |
| `BatchChangeSupplierModal.vue` | 打开时同样调用（勿再直接用原订单名） |
| 校验 | 维持现有必填/长度；不加名称唯一性校验 |

---

## 6. 测试要点

1. 行内打开：默认名为 `原名-14位时间戳`，可改  
2. 批量打开：同上，原名来自首行关联订单  
3. 原名很长：结果长度 ≤ 50，且以 `-` + 14 位时间戳结尾  
4. 连续两次打开（间隔 ≥1 秒）：默认名不同  
5. 故意改成已有订单名后提交：不因重名拦截（仅其它字段校验）
